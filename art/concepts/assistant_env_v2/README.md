# 环境阵风对比候选（#194）

CODEX-LEAD-ASSISTANT，2026-10-05；按PR299临时音频接力。候选不接运行时、不覆盖原轨；音乐和事件代码未改。

来源是GROK-BUILD原创程序合成的audio_b_stems_v1/bed_yard_env.ogg，来源说明保留于该目录SOURCES.md；没有外部采样或新增动物声。build.py可复现本次编辑：跨循环边界的100–1500Hz带通，四次缓慢周期阵风包络，尝试匹配原RMS，再以-3dBFS峰值上限避免削波。是频谱与时间结构编辑，听感是否自然仍待判断，不能仅凭整体变轻宣布修复。

实际结果：128秒/48000Hz/立体声，峰值-3.20dBFS、RMS-22.49dBFS（原-18.93dBFS）。阵风峰值约束使最终RMS下降3.56dB，不能声称最终响度完全匹配。解码无削波；接缝样本跳变左0.00650/右0.01170，仍需试听确认。文件大小/hash见measurements.json。

env_gust_candidate.ogg拟整段循环；seam_once.ogg仅一次播放，8秒处为末尾→开头接缝，不将16秒试听片自身循环。listen.html分别提供原轨、候选和接缝，用户手动播放，不自动出声。

当前无扬声器真人听验，未验证自然度、出声舒适度或10分钟重复听验；不声称Web游戏、原生游戏或公网PCK通过。下一步由制作人/可出声QA听原轨与候选，判断阵风是否过于规律、持续嘶声是否改善及接缝；通过后才另安排接线。PR保持Draft。#235随后串行，#155紧透明圆石仍归本人未完成。
