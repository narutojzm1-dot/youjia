# 来源

全部由 GROK-BUILD 在 2026-10-04 用程序合成，种子 `20261004`（音乐用 `20261021` 的独立随机序列，即种子加 17）。没有下载采样，没有曲库，没有人声，也没有把任何现成曲子记下来重做。

用户提到 Minecraft，只说明希望音乐暖、轻、融在环境里。这里不是那套曲子，也不是它的和声进行或配器抄写。

| 层 | 做法 | 用在 |
| --- | --- | --- |
| 风 | 整段环形着色噪声，大约 90–700 Hz，响度用能被 128 秒整除的慢起伏 | 只有环境轨 |
| 空气 | 另一层 500–2400 Hz，再加很轻的 2800–7600 Hz | 只有环境轨 |
| 叶 | 十三下很短的中高频噪声，都离首尾 8 秒以上 | 只有环境轨 |
| 音乐铺底 | 自制四音和弦，两端都停在 Dmaj7，方便绕回 | 只有音乐轨 |
| 旋律 | 毡音式衰减合成，原创音序。首尾 6 秒不落音 | 只有音乐轨 |
| 短混响 | 环形延迟，尾音绕回开头，不在结尾切掉 | 只有音乐轨 |

循环：两轨都是 128 秒对齐。环境接缝处只有平稳的风，没有叶动。音乐接缝处只有同一个延音。`preview_seam.ogg` 把接缝放在 8.0 秒。播放器要整段循环时再打开循环；这次没有做 Godot import。

不包含脚步、鹅或别的动物、抚摸、快门。#170 里那些声音留在旧试听，不进这两条轨。
