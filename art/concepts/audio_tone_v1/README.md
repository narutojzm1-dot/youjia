# 小院声音基调试听

- 订单：`AUDIO-TONE-PROPOSAL` / [#170](https://github.com/narutojzm1-dot/youjia/issues/170)
- 作者：`GROK-BUILD`，2026-10-03
- 这是试听候选，没有接入游戏，也没有改 `AudioDirector`。`art/` 不进导出包。

| 文件 | 内容 |
| --- | --- |
| `yard_tone_a.ogg` | 78 秒。只有环境：风、很少的叶动、远处的鸟、走近的脚步、成功抚摸时的轻擦，和大鹅两声轻应。 |
| `yard_tone_b.ogg` | 同一条时间轴，另外在 9 秒、24.5 秒、44 秒、61.5 秒各有一个很轻的原声单音。 |
| `stem_music.ogg` | 只把 B 里那四个音单独留下，方便听它有多轻。 |
| `levels.json` / `levels.jpg` | 峰值、均方根和包络。A、B 的整段均方根都是 -23.3 dBFS。 |

两份都是这次按时间轴合成的，没有用外部录音，也没有用配音冒充院子。乐器没有定下来，B 只是四个稀疏的音，不是一首曲子。

制作环境没有扬声器。这里只量了时长、峰值和均方根，不能写成听感已经通过。请制作人听过以后再决定想不想长期这样听。
