## 路线与边界

- 进入：从现有近郊远端交接，不新开空白院门，不在标题加传送。
- 行走：桥面与石滩落脚；水面和桥栏不可走。
- 返回：同一条路回近郊，再沿现有返院。随时可回，不设解锁或打卡。
- 状态：时辰、天气、人物、背篓物品沿现有探索往返，不另建时钟或背包。
- 不做：村落、集市、交易、任务门、强制顺序。
