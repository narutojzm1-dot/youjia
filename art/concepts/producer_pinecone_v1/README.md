## 实际渲染与候选参数

world.png和presentation.png是Godot4.7.2 OpenGL独立Sprite2D场景的原始截图，无像素后处理。并非正式游戏截图，不含人物/碰撞/篮子/成功事件，展示框与英文只是尺寸试验，不能照搬成正式UI。

以alpha>=200主体高611为参照，原画像素高24、原图坐标(1000,688)，等比映射1280/1672后主体高约18.37屏幕像素。展示主体高64像素。候选底部锚点(636,954)，不是碰撞或拾取范围；不要把1254画布高度当主体高度。原画里的松果/落羽仍在，待清底，不能把原画副本当第二个可拾取物。

render_study.gd可在独立Godot项目Node2D上挂载复现，准备本母版原样复制为pinecone.png、恢复包02_near_path.png原样复制为near_path.png，设置1280×720、gl_compatibility，先导入后使用图形设备运行；输出world.png和presentation.png。不要直接接入生产场景运行这个自动退出脚本。
