## Visual review

The angry goose and llama/cow/horse relationship now read clearly. Existing wool, cream/caramel colors, and the two sheep personalities are preserved. All seven bodies and feet are visible. The horse is deliberately substantial and has coherent four-legged equine anatomy, without tack, clothes, or office props.

Caveats for approval: the horse has a long, full mane/tail and a relatively tall silhouette; the goose's wing is considerably flared and should be treated as the expression reference, with a calmer same-body base pose prepared later if needed. Cow and horse weariness is a subtle expression cue, not a literal work narrative. The sheet alone does not implement teasing behavior.

This is not a runtime atlas. Individual transparent cutouts, canonical scale/ground anchors, and same-body llama expression variants remain subsequent production work after approval. The seven character bases should be locked before animation. Exact generation prompt is stored in `generation_prompt.txt`.
