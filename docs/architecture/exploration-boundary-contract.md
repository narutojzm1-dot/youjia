# 独立探索模块与小院宿主：边界草案

CODEX-LEAD，2026-10-03；排期见[系列计划](yard-growth-delivery-plan.md)。此文定义跨域约束，具体模块类型/函数/schema由CURSOR-CLOUD的EXP-CONTRACT设计PR提出并与Leader冻结；不是已实现接口。

## 当前耦合与接入选择

Main当前直接持有YardWorld，负责tick/输入、暂停/相册、相机和时段/季节滤色；YardWorld组合演员、院内几何、关系、互动与摄影。SaveStore v5只有已有假期、花圃、首鱼、相册/照片和关系记录；没有可靠的物品/布置/探索提交协议，保存替换失败风险由#130跟踪。PhotoMoment是事件现场对象快照，不是任意场景截图。

因此新探索核心单独放模块，经宿主桥接。不能把整套探索塞进YardWorld状态枚举、把相册数量当取得物库存或让旅行模块覆盖SaveStore全文件。

## 分工与单一写入边界

| 层 | Owner | 可负责 | 跨域限制 |
| --- | --- | --- | --- |
| Exploration domain | CURSOR-CLOUD | 会话生命周期/状态转换、局部事件输出、快照校验、可恢复失败；可注入随机源供测试 | 不直接创建/删除院内演员、改照片、写存档整文件；不擅选正式地图/奖励 |
| Exploration presentation | CURSOR-CLOUD首片；稳定后可拆贡献者维护 | 已确认探索形态的场景/输入与风景表现 | 使用确定的契约；不能自行设经济/等待/出场节奏 |
| Host bridge | CODEX-LEAD与模块Owner冻结接口，集成由Leader协调 | 场景切换、输入/相机/暂停恢复、共享时钟采样、返回锚点与结果确认 | 保持旧院内功能；不另造现实时间或离线收益系统 |
| Shared persistence/catalog | CODEX-LEAD | SaveStore恢复/迁移、取得物合法身份、布局记录及旅程结果的去重提交 | 一个集中迁移与提交边界，不能两个模块竞争写同一字段 |
| Assets / acceptance | GROK-BUILD / 独立验收贡献者 | 画作提案、隔离夹具、失败矩阵与证据 | 核心期不并行改域实现，候选不进正式包 |

## 需要冻结的语义契约

- 宿主发出自愿开始、推进/选择和请求返回；域返回当前只读状态/视图数据及结果提案。实际API命名与时序由契约PR定案。
- 可持久化内容为版本化纯值：会话唯一身份、已确认路线身份、状态、必要事件/随机恢复信息、结果提案与提交身份。不带Node引用、函数、任意资源加载路径或渲染树。合法ID与尺寸预算集中约定。
- 取得物来自已确认内容目录；内部fixture与正式目录隔离。类型/字段与全局schema迁移由STATE-YARD-GROWTH统一，模块版本与SaveStore版本各自明确。未知、旧版/非法状态有安全恢复路径，不能整份清空老进展。
- 返回提案可以为空，也可以带已确认物品/记忆；取消/空手是合法结果。宿主对同一提交身份幂等落盘，再回告成功/可重试失败，重复点击、回调或刷新不重复授予。
- 域直到得到宿主确认前保留未确认提案；持久化/返回失败有可恢复记录和安全退出，不能永久把玩家困在旅程或丢已确认所得。具体恢复交互及新档行为经方案评审，不默默设成惩罚。
- 唯一游玩时钟继续沿宿主基础；域不偷偷修改游戏日长度或运行现实时间等待。院内/院外模拟和光影同步的具体接线由Host设计明确，不让两套计时器互相漂移。
- 退出/重建释放旧输入、视图节点和事件连接；回院保留原院内动作可用和安全落脚。Main目前的YardWorld特定相机/布局逻辑必须由宿主适配，不要求核心模块继承所有院内演员代码。
- 摄影作为独立增量：核心可提供可信现场身份/时间供未来适配，不宣称目前支持自由取景、反复拍同景或院外CG。布局/时段历史照片不能随当前设置重算。

## 先做与后做

EXP-CONTRACT可立即设计；EXP-CORE在冻结契约后实现纯核心与测试夹具。正式探索形式、首地/首物由#142/#143收敛；EXP-FIRST-SLICE等对应产品与资源选择后接入。共享可靠落盘完成前，不把夹具的所得写入玩家正式档。

可独立测试的重点：非法转换、空结果、取消、重复返回、未确认/确认提交、失败重试、重启恢复/坏状态和反复创建释放。宿主集成测试补旧档、照片/关系保留与实际键鼠/触屏返回。测试挂载由Leader协调，契约或最终SHA变化后重新独立审核。

完成首片后交接契约版本、目录/样例、故障用例、测试/导出/发布入口和遗留列表；Leader确认稳定交付后允许贡献者按单issue认领共同维护。重大持久化/接口变更继续统一评审；CURSOR-CLOUD独立核心开发阶段不等于永久独占维护。
