## 玩家该看出来什么

照片里的大鹅是踩在马背上，不是飘在马旁边。翅膀在扑，脚还在马背上。没有马鞍，没有任务提示。低动效时停在这一张，不要闪。

## 不要用现有的哪张图冒充

| 现有图 | 尺寸 | 锚点 | 为什么不能当乘骑帧 |
| --- | --- | --- | --- |
| `goose.png` | 1254×1254，1,212,584 字节 | (628, 1186)，画布朝右（manifest `native_facing` 1） | 站在地上、翅膀已经张开。贴到马背上会悬空 |
| `goose_calm.png` | 888,242 字节 | (694.5, 1216) | 收翅站立，脚在地面 |
| `goose_rest.png` | 1,016,561 字节 | (696.5, 1078) | 趴在地上，不是骑着 |

场上大鹅配置的 `native_facing` 是 -1，也就是把朝右的原画镜像到朝左，和马的场上朝向一致。新画按 `goose.png` 的朝右来画，运行时沿用现有镜像，不要另画一套朝左的。

`horse.png` 是 1,508,497 字节、朝左的低头站立。鹅的新文件里不要画上马，也不要画地面或影子。

## 只要这一张

一只和现在同一只白鹅：脸、羽色、笔触、透视不变。

- 双脚踩实，能看见趾。身体略向前倾，重心在两脚之间，不是后仰摔倒，也不是飞起来。
- 翅膀展开到扑腾的中途，左右羽缘完整留在画布里。不要把 `goose.png` 的翅膀压扁当这一帧。
- 画布 1254×1254，透明。羽毛不裁出边（现有 `goose.png` 的 `border_pixels_alpha_gt16` 是 0，新图也要是 0）。
- 量脚底接触点作为 `ground_anchor`。因为是踩马背而不是踩地，锚点可以和 (628, 1186) 不同，但左右脚必须落在同一条接触线上，切换时不能跳。
- 记录 `alpha_bbox`、`native_facing` 1、文件 SHA-256。场内可见高度仍约 70 世界像素，和现在晴天鹅的比例同一档。

issue 里写过「和 goose.png 交替」。那样会把站立鹅嵌进马背。所以第二帧如果以后要做，也必须是另一张脚还在马背上的完整画。这一轮只定一张，低动效用这一张。

## 包体和接入

- 源 PNG 目标不超过 `goose.png` 的 1,212,584 字节。超过就要说明取舍，并以正式 PCK 的净增量为准。
- 挂点等 PR #65 / #72 合入 main 之后再定。在那之前不改 `FeltActor`、相册或导演脚本。
- 这张画不表示鹅和马已经结仇或结伴。关系仍只批准了鹅和羊驼安静共处。

## 产品还要看的

画完之前先确认：一张扑翼中的乘骑是否够，还是必须两张脚都在马背上的画交替。确认前不要开工绘制。
