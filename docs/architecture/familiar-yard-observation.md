## 建议垂直切片（需用户确认顺序）

### 切片 A — 抬头看天（依赖 REQ-005 云带批准）

- 目标：静止或缓移的叠加云带，使晴/阴天空可观察。
- 产出：按 sky-cloud-plan 的 B 层；低动效静止帧。
- 不做：雨雪、火烧云（可进 A2）。

### 切片 B — 安静停留的可读反馈

- 目标：玩家一段时间几乎不动时，世界仍有轻变化（云、远处动物、树叶），无催办文案。
- 产出：停留检测 + 既有系统的低噪声组合；可打断。
- 不做：强制引导、「今日观察任务」。

### 切片 C — 自由取景原型（高风险，最后）

- 目标：可选的短时「看看」模式：轻微调整取景/前景暗示（汽水瓶仅为例子，不预定道具）。
- 产出：可跳过的原型 + Web 性能记录。
- 不做：完整摄影 UI、图鉴收集、评分。

### 切片 D — 静坐观察演出（可选）

- 目标：主人静坐时，远景动物事件 → 短跟随 → 近景 → 可选入册；全程可打断。
- 产出：一条剧本级演出管线原型。
- 不做：每次互动长 CG。

## 推荐推进顺序

1. 用户确认 REQ-005 云带 B → 实现切片 A。  
2. 切片 B（无新美术也可先做一部分）。  
3. C/D 仅在 A/B 验证「愿意停留」之后再开。

## 验收原则（任一切片）

- 可错过、可离开，无红点/完成率。
- 正式 Web 构建 + docs/playtests/ 证据。
- 独立子代理审核最终 commit。
