## 垂直切片（已确认）

### 切片 A — 抬头看天（进行中，依赖 REQ-005 云带 B）

- 目标：静止或缓移的叠加云带，使晴/阴天空可观察。
- 产出：按 sky-cloud-plan 的 B 层；低动效静止帧。
- 不做：雨雪、火烧云。

### 切片 B — 安静停留的可读反馈（下一步）

- 目标：玩家一段时间几乎不动时，世界仍有轻变化（云、远处动物、树叶），无催办文案。
- 产出：停留检测 + 既有系统的低噪声组合；可打断。
- 不做：强制引导、「今日观察任务」。

### 切片 C — 自由取景原型（后置；先无道具）

- 目标：可选的短时「看看」模式：先做镜头轻微推进，**不**引入实体前景道具。
- 产出：可跳过的原型 + Web 性能记录。
- 不做：完整摄影 UI、图鉴收集、评分、汽水瓶实体。

### 切片 D — 静坐观察演出（本周明确延后）

- 目标：主人静坐时，远景动物事件 → 短跟随 → 近景 → 可选入册；全程可打断。
- 产出：一条剧本级演出管线原型。
- 不做：每次互动长 CG。
- **排期：** 延后，不在本周切片内。
