# REQ-20261002-013 · 偶遇抓拍与可翻的旅人手账

## 玩家体验与分工

拍照是旅人路过时留下的一张真实照片，不是任务/打卡。本切片由 `MANUS-CONTRIBUTOR` 独立负责照片规则、题词 provenance 和相册阅读界面；REQ-011 的互动后世界回响与小故事仍由其独立 issue #45 承载，本切片**不实现**离线成长、剧情状态机或关系值。REQ-001 的行走与互动动作属于 PR #27，本切片不改它。

## 数据与呈现的分离

1. `ExpressionCatalog` 声明哪些真实世界状态允许照片；`YardWorld` 对玩家距离、姿态、物种邻近、日期和天气做实时验证。没有满足条件的场景，不创建相册记录。新事件只用已经存在的完整水彩动作和实物关系：在岸边真正伏卧的大鹅、彼此靠近的两只羊、靠近大鹅的鸭子。
2. `PhotoMoment.capture` 在触发时保留真实可见场景、假期天数与一次性抽出的**有界题词变体序号**，并通过 `sanitize` 严格验证。旧 `version:1` 无此字段时继续使用历史原题词；无 `day` 时只显示旧标题。重复看相册不重新抽签；重开存档、改变语言仍指向同一事实。题词只能描述规则保证或画面实际发生的动作，不能拟造生气、感谢、吃东西等不可证实的事情。
3. `PhotoDiary` 只根据已存变体 ID 选中英双语短句，不保存翻译后的文字、不自行随机。`SaveStore` 仍是单一权威存档；没有第二份可能漂移的相册缓存。
4. 相册仅从 `collected` 中读真实照片，按首次获照顺序浏览：宽屏摊开两页，竖屏每次一页；每页一张放大的拍立得、有真实日期题词和事件小注。已有照片但旧存档没有世界快照时可显示旧角色画片，不能声称那是拍到的现场。空相册显示宁静留白，不展示锁住的条目；纸张、书脊和拍立得框取自仓库 `scrapbook_paper.png` / `polaroid_frame.png`，所有文字由 Godot 控件本地化绘制。上一页/下一页按钮、键盘左右键和触屏翻动共同工作；Esc 仍合上书并归还世界输入。无完成率、未解锁槽、红点、倒计时或收藏奖励。低动效直接换页、无强制动画。

## 抓拍条件与防抢占

| 场景 | 观察条件 | 取景 | 文案只说已证实之事 |
| --- | --- | --- | --- |
| 岸边的鹅 | 大鹅真实 `state=rest` 且使用完整伏卧画帧；玩家在近旁，第 2 天起 | 大鹅现时轮廓和脚下岸草 | 大鹅伏下身歇着 |
| 两只羊 | 羊 A 与羊 B 的真实空间距离在阈值内、玩家看见，第 2 天起 | 两只羊同时入镜 | 两只羊靠得近了一点 |
| 池边来客 | 一只鸭与岸边大鹅实际邻近、玩家看到两者，第 3 天起 | 现场最近的鸭与鹅 | 鸭子游到大鹅附近 |

观察类事件优先级低于主动抚摸、投喂及已有的羊驼主线；每种照片仅第一次入册，不许错过惩罚。实际照片构图不得摆拍或改变演员姿态。测试必须证实未满足距离/卧姿不触发、实际抓拍存档、旧快照字段缺省、题词变体双语稳定、相册翻页/缩屏/返回院子。
