# 旅人可走范围扩展计划

2026-10-03；制作人授权规划扩大，具体区域未标定、未实现。框架Owner CODEX-LEAD [#125](https://github.com/narutojzm1-dot/youjia/issues/125)；资源盘点Owner GROK-BUILD [#126](https://github.com/narutojzm1-dot/youjia/issues/126)。

## 已核对的当前限制

基线main e05ff693feda91df083f6a652dd8ee8477088176。YardGround.lawn()是14顶点凹多边形，包围范围x185–900、y430–648；lawn多边形投影面积80924世界平方像素（shoelace计算；未扣水体/身体安全余量，净可走面积需另测），占1280×720画面8.8%。画面还有天空/山/房屋，不能把这个比例当成“只有8.8%地面可走”，也不能用矩形面积当新增有效空间。池塘另由中心(705,592)/半径(148,52)椭圆禁行。

YardWorld._bind_grounds把同一lawn赋给玩家和陆生动物；YardGround.route及_clear_segment内也硬编码lawn。Vacationer的运动和YardBodies身体避让均检查walk_ground。扩展不能只改lawn顶点、WORLD_SIZE或速度。

Main已有宽屏轻微跟随和竖屏横向跟随；未证明新靠下/侧缘区域在手机HUD下能完整看到脚点或正确点击。depth_at按420–650插值后clamp，新增近景可能落在同一最大depth，需画面核对，不盲目继续放大角色。

| B 独立边界 | 一个已确认的院内扩展切片 | 玩家范围与动物原作息分离；键盘、点击/触屏、追踪/安全站位与路由使用同一玩家polygon，原区域及往返稳定；动物不会因此穿栏或进入前景。 |

首片要让玩家多一段自然的散步/观察路线，而非扩大几处走不出的角落。当前没有标定证据，不预报面积增长百分比或承诺新坐标可用。

## 最小技术路线

- 保留既有lawn/home/pond作为动物安全约束；新增玩家专用地面描述。具体函数名在实现时确定，不建设通用地图编辑器。
- 路由goal校验、可视线段与路径节点须接受同一地面polygon（原调用兼容默认lawn）；玩家所有散步/互动追踪入口传玩家地面，不留两套硬编码区域。规划身体安全余量，窄路不能仅按点能走就算成立。
- 热点画面命中、approach安全站位与实际动物目标分别核对；不因多走一块地就新添互动收益、抢已有输入优先级。MANUS热点/反馈PR若活跃，先协调共享YardWorld文件。
- 牵引涉及玩家与羊驼不同地面：先保证原范围内引导不变；玩家独有区域不可要求羊驼穿入，路线失败可取消/退回安全站位，不瞬移、不修改关系记忆或自动判互动成功。
- 替换地面后setup/重置起点保持有效；核对当前存档是否包含位置字段，若有无效旧位置安全回退，若没有不为本片增加位置持久化。照片保存原现场与坐标，不能重新解释历史照片。
- 脚点接地、身高透视、前景植物遮挡、镜头边缘/手机HUD和屏幕→世界点映射要一起核验。固定构图天气一致仍依#51，不能晴天可走而阴天脚踩不同物件。
