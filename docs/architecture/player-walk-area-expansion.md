## 已核对的当前限制

基线main e05ff693feda91df083f6a652dd8ee8477088176。YardGround.lawn()是14顶点凹多边形，包围范围x185–900、y430–648；lawn多边形投影面积80924世界平方像素（shoelace计算；未扣水体/身体安全余量，净可走面积需另测），占1280×720画面8.8%。画面还有天空/山/房屋，不能把这个比例当成“只有8.8%地面可走”，也不能用矩形面积当新增有效空间。池塘另由中心(705,592)/半径(148,52)椭圆禁行。

YardWorld._bind_grounds把同一lawn赋给玩家和陆生动物；YardGround.route及_clear_segment内也硬编码lawn。Vacationer的运动和YardBodies身体避让均检查walk_ground。扩展不能只改lawn顶点、WORLD_SIZE或速度。

Main已有宽屏轻微跟随和竖屏横向跟随；未证明新靠下/侧缘区域在手机HUD下能完整看到脚点或正确点击。depth_at按420–650插值后clamp，新增近景可能落在同一最大depth，需画面核对，不盲目继续放大角色。

## 最小技术路线

- 保留既有lawn/home/pond作为动物安全约束；新增玩家专用地面描述。具体函数名在实现时确定，不建设通用地图编辑器。
- 路由goal校验、可视线段与路径节点须接受同一地面polygon（原调用兼容默认lawn）；玩家所有散步/互动追踪入口传玩家地面，不留两套硬编码区域。规划身体安全余量，窄路不能仅按点能走就算成立。
- 热点画面命中、approach安全站位与实际动物目标分别核对；不因多走一块地就新添互动收益、抢已有输入优先级。MANUS热点/反馈PR若活跃，先协调共享YardWorld文件。
- 牵引涉及玩家与羊驼不同地面：先保证原范围内引导不变；玩家独有区域不可要求羊驼穿入，路线失败可取消/退回安全站位，不瞬移、不修改关系记忆或自动判互动成功。
- 替换地面后setup/重置起点保持有效；核对当前存档是否包含位置字段，若有无效旧位置安全回退，若没有不为本片增加位置持久化。照片保存原现场与坐标，不能重新解释历史照片。
- 脚点接地、身高透视、前景植物遮挡、镜头边缘/手机HUD和屏幕→世界点映射要一起核验。固定构图天气一致仍依#51，不能晴天可走而阴天脚踩不同物件。

### 坐标和安全口径

- YardWorld 创建背景 Sprite2D 时 `centered=false`，默认原点；天气更新按 WORLD_SIZE / texture_size 缩放。因此1920×1080底图以2/3比例渲染到世界 `(0,0,1280,720)`，工具完全使用同一矩形。鼠标使用 canvas 实际 CSS 矩形逆算到世界脚点；不能把屏幕截图像素直接当世界坐标。
- 玩家 position 是脚点；Vacationer 图片中心向上偏移半张源图高度，不能拿人物图中心代替脚点。身体碰撞基础半径 `(10,6)` 乘 depth，depth 在 y420–650 从0.82到1.18。工具用全区最大 `(11.8,7.08)` 做保守足迹边界内缩；这是地面碰撞范围，**不是头发/手臂/全身可视轮廓**。
- 生产 lawn/pond 边界实际只检查脚点，不按身体半径收缩；本工具额外的边界安全余量是候选设计条件，不能描述为当前已有防穿保证。边界内缩使用足迹归一化后的线段最短距离；池塘禁区使用椭圆按 `1+max(11.8/148,7.08/52)` 放大，依据三角不等式保守包含足迹扩张。
- 实际动态障碍来自 `physical_obstacles` 的动物足迹（鸭除外），路由额外留 `(2,2)`。表格采用晴天出生位置；动物随后移动、阴天鹅位置不同，结果不是全时段通畅保证。石头、花盆、栅栏、前景植被没有独立生产碰撞体，**未把图上的它们凭空当作已建模障碍**，因此几何有效不等于视觉可走。

### 画面核对与剩余判定

实际查看叠加截图后，左岸候选下边靠近花盆和岸边石块，栅栏前沿右尖靠近池塘石岸；现有水体椭圆并不包含全部画中石岸。故这两项不能因100%几何连通直接启用，需 GAME-PRODUCER 确认哪些脚点真正落在可走草地、哪些应缩回或需要遮挡/资源处理。门前下段可作为优先核对的小范围候选，但其左侧靠前景植物、下缘涉及手机HUD，仍未获具体区域批准。当前未证明任何候选完全无需补图；没有发出新美术制作或启用承诺。

技术硬边界：YardBodies.route 的 AStarGrid2D 固定 `Rect2i(14,33,65,23)` / CELL12，网格节点世界x168–936、y396–660；门前候选最低y672越出旧网格。即使直达线段偶尔成功，也不能据此认为绕障往返成立。后续B必须同时参数化玩家路由范围和 ground，保留动物lawn；depth在650后不再增大。玩家独有区不可驱使羊驼进入，牵引只能留在两者可走交集，失败应取消/回到安全站位，不瞬移、不自动完成互动。
