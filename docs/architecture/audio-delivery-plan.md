# 小院声音交付计划（DIR-20261003-AUDIO）

来源：[GAME-PRODUCER #162](https://github.com/narutojzm1-dot/youjia/issues/162)。用户授权规划总体音效；以下是分期与技术边界，具体听感/乐器/曲目/正式素材仍待可听样片核对。当前没有新增正式音频或发布。

## 基线与定位

源码基线 `4574a59e1a834ca0bfa312086b061d233305645e`：`autoload/audio_director.gd` 的 CUES 全为空路径；已有总线/静音/音量/音乐交叉淡化、声部池及解锁接口，未发现正式 wav/ogg/mp3。方法存在不代表实际Web手势/暂停/后台恢复已经通过听验。当前小院主要调用暂停接口，模板迷宫事件不能作为小院声音语义。`assets/template/provenance/AUDIO.md` 的历史静音说明不阻止本次规划授权。

制作人建议环境和真实行为声为主、音乐偶尔陪伴，保留留白。声音服务静坐、动物个性与我对世界的影响；不能靠循环齐鸣、突发巨响和奖励叮咚驱动操作。此为候选声音基调，不表示音乐风格已批准。静音仍须完整可玩。

## 接入必须定义的边界

事件记录“发生了什么”，音频适配决定“怎样听到”；成功/未命中、实际位移、真正拍照与旧相册浏览要区分。现AudioStreamPlayer没有自然对象定位能力，距离/方向方案需明确，不能把全局声部池视为空间声音。音乐/环境/互动与总静音的控制复用设置机制，保持用户选择，不臆造新存档。

复用一个游戏时钟；进出场景和后台恢复不积压补播、不重复开声源，不每换时段重开整首音乐。暂停、缺失资源、手势未解锁等有明确行为；资源加载成功和headless布尔返回不是听感证据。

## 验收与用户材料

样片先解决“这个小院听起来舒服吗”，不让用户逐条批准格式或脚步参数。源码/逻辑验证、实际出声和人能感知的舒适度分别记录。正式首片需十分钟听验（耳机/扬声器）、事件对应与重复密度、静音可玩、设备/浏览器与手势/后台、包体和性能；日夜切片再验至少一次完整时段衔接。GAME-QA后续按实现范围复测，尚未执行项不得记通过。

所有候选记录来源授权和制作过程；最终SHA独立审核、必要回归/Web/浏览器验收与发布后清单/PCK核验按仓库规范执行。新样片通过#146由Leader/制作人汇总给用户，选定结果回写策划与台账。
