# REQ-005 / REQ-012 · 天空与云层表现方案（草案）

- 关联：REQ-20261002-005（天气/季节）、REQ-20261002-012（时段天空与反复观看）。

- 日期：2026-10-02

## 目标

让同一小院在观察时，天空不只是「阴天换底图 + 全屏滤色」：

1. **时段光线**：早晨 / 正午 / 傍晚可辨（现有 TOD 滤色可保留为过渡）。
2. **云层可读**：云形、疏密、偶尔火烧云成为可反复观看的内容。
3. **成本可控**：优先叠加型水彩层，避免为每种天气导出整张 1280×720 新院子。

## 不做

- 不把云层做成每日任务、收集图鉴或签到。
- 不引入雨雪惩罚、离席损失。
- 本文件不授权新 PNGs 合入 main；制作前需用户确认题材与张数。

## 候选分层（由浅到深）

| 层级 | 内容 | 技术 | 成本粗估 | 风险 |
| --- | --- | --- | --- | --- |
| A. 现有 | 晴/阴院子画 + TOD/季节滤色 | 已上线 | 0 | 云本身仍不可观察 |
| B. 云带叠加 | 1–2 条半透明云带（水彩），缓缓漂移或低动效静止帧 | 独立 Sprite/Canvas 层，跟随天气 modulate | 2–4 张完整画作 | 需与晴阴底图透视对齐 |
| C. 火烧云变体 | 傍晚 TOD 窗口切换暖色云带帧 | 复用 B 的锚点 | 再 +1–2 张 | 避免与相册光线打架 |
| D. 雨/雪 | 粒子或短循环水彩条 | 新系统 | 高；Web 性能敏感 | 需单独产品确认 |

**建议下一实现切片只做 B 的「晴天一帧云带 + 阴天一帧云带」**，不动雨雪；火烧云进 C。

## 与 REQ-012 的边界

- REQ-012 的「静坐摄影演出 / 自由构图」不在本方案范围。
- 本方案只解决「抬头能看出天在变」；摄影演出另开设计。

## 验收（若批准 B）

- 晴/阴切换时云带与院子画构图连续，不出现贴纸矩形。
- 低动效下云带仍可读（静止帧即可）。
- 不改存档字段；旧档直接可见。
- 正式 Web 构建 + playtest 记录。
