## 3. 三段体验

### 3.1 停下看景

- 流程：走近停留点 → 松手即停 → 按 E / 点顶部「停下看看」→ 进入观察态：角色不动，相机收进这一处小景；底部只显示「只是看看」与「继续走」。
- 为什么值得停：停留点是一处能完整看懂的小景（主体、周围环境、角色站在哪），不是一个要触发的目标。占位停留点 A（院门外）和 C（远处）都只看不带，C 甚至不调用核心——看景本身就是内容，不计任何进度。
- 随时结束：观察态里随时可按 R / 点右上角回院；继续走则按 E、点「继续走」或直接按方向键。

### 3.2 空手中途返回

- 流程：在 B 停下看，核心显示有一样可带的东西，但**不会自动带上**；玩家点「继续走」或直接回院。
- 院内文字：提交在途时说「空手回来了，正在记下这趟散步…可以先在院子里走走」，核心确认后才说「空手回来了，这趟散步已记下」；结果未知、失败、重试各有空手文字，**从不出现「已收好」**，假宿主不发放任何东西。
- 意义：验证「空手回来」是正常的一次散步，而不是失败或漏拿。

### 3.3 带一个占位物中途返回

- 流程：在 B 停下看 → 点左下「带上」（核心 `take`）→ 可以「放回」（核心 `release`）→ 再带上 → 不必走回起点，在 B 直接回院。
- 院内文字沿用 #200：在途「正在收好带回的东西」，确认后「带回的东西已收好」，只发放一次。
- 占位物是 #176 夹具里的 `formal.find.reed`，仅为测试夹具，不是已批准的正式物品。

## 4. 横竖屏同一停留点取景对照

同一停留点 B（x=2200），角色站在停留点正中或偏右 110：

| 视口 | 跟随：缩放 / 可见宽 / 小景可见比例 / 角色高 | 收景：缩放 / 可见区 / 小景可见比例 / 纸边占比 / 角色高 |
| --- | --- | --- |
| 1280×720 | 1.00 / 1280 / 100% / 96 px | 与跟随相同，无纸边 |
| 1920×1080 | 1.50 / 1280 / 100% / 144 px | 与跟随相同，无纸边 |
| 844×390（横放手机） | 0.54 / 1558 / 100% / 52 px | 与跟随相同，无纸边 |
| 390×844（竖屏） | 1.17 / 333 / 61–64% / 113 px | 0.70 / 560×1212 / 100% / 41% / 67 px |
| 360×780（竖屏） | 1.08 / 332 / 61–64% / 104 px | 0.64 / 560×1213 / 100% / 41% / 62 px |

结论（研究建议，不是画面验收）：

- 横屏下两方案一致，停下就能看全小景。
- 竖屏跟随只能看到小景约六成，主体被切开，必须来回挪动拼接画面——这正是 GAME-PRODUCER 在 #201 指出的问题，已在测试里作为基线复现（`portrait follow framing shows only part of the scene`）。
- 收景方案在横竖屏、停留点 ±110 范围内都能一次看全小景和角色（测试覆盖 3 个停留点 × 3 个站位 × 5 种视口）；代价是竖屏上下约 41% 是画卷以外的装裱底色，角色在屏上约 67 px。录像里 HUD 正好落在纸边上，没有压住景物，这是一个可利用的性质。
- 建议首片按「行走时跟随、停下看时收景」研究；纸边如何表现（装裱、题字、天空 / 前景向上下延伸）交 ART-DIRECTOR 与 GROK-BUILD，不在此锁定。

## 5. 连续操作检查（走近—松手观察—选择／不选择—中途回院）

竖屏 390×844 下一次连续完成（测试第 4 节与演示录像 17–33 秒）：

1. 按住右半屏走向 B，松手即停（之后 5 帧位置不变）。
2. 点顶部「停下看看」进入观察态；没有任何行走来源残留。
3. 观察中误触右半屏（含拖动）和左半屏各一次：角色不动，两次都被拦下计数。
4. 点左下带上 → 再点放回 → 再点带上；全程角色位置不变。
5. 点右上角回院：回院顺序与 #200 一致，研究画卷新增的信号在小院接管时已断开。

另测：一根手指还按在半屏上时按 E 停下看，观察态会清掉这根手指，抬手后也不会续走；键盘在观察态按方向键直接继续走（视为有意操作）。

| 9 | 走过停留点但不停下看时，核心停留点不变 | 走过 B 不按 E，再回院 | 建议正式接入仍以「停下看」为到达依据，经过不计任何东西 |
| 10 | 回院是瞬切，没有「从院门回来」的空间关系（#200 留给本单） | 任意回院 | 本切片保持瞬切，确保回院顺序与输入失效不受过渡影响；建议把短淡入或院门提示作为表现候选，低动效下仍瞬切，交 ART-DIRECTOR |

起停缓动与视差仍只是表现候选：本切片只在取景切换（进出观察、按 F 切换方案）时加一个过渡，低动效下直接切换；平时相机与 #199 一样直接跟随角色，行走没有相机缓动，松手即停（测试第 2 节断言行走时相机与跟随取景完全一致）。

## 7. 首片节奏 / 构图需求建议（交 GAME-PRODUCER / ART-DIRECTOR / GROK-BUILD）

- 每个停留点是一处**停稳即可看懂的完整小景**：主体、周围环境、角色站位同时在画面里，竖屏不需要来回挪动拼接。
- 相邻停留点之间保留可见的景色线索（远山、小路、水流延续），让玩家愿意继续走，而不是地图式全览或路标。
- 至少一处只看不带；至少一处可以带一件东西，带不带都行、可以放回；不以走到底、捡齐或停留时长计进展。
- 任何停留点都能回院（或在画面上明确标出能回院的范围）；画卷尽头没有奖励。
- 观察态的操作只有：带上 / 放回（有东西时）、继续走、回院；不加计时、提示箭头或待办。
- 不锁分钟数、停留点数量、掉率或画卷长度；上述数值都是实验参数。

## 9. 地点与物件候选（有理由的候选，交 GAME-PRODUCER / Leader 汇总用户确认）

以下只是候选，不是决定；正式资源前仍需用户选择：

- 去处：**院门外的近郊小路**——从熟悉的院门出发，延续阿尔卑斯山脚的同一画风，不需要新地图概念。
- 停留点候选：院门外的栅栏与远山（只看，与小院相连）；小溪或木水槽边（可带一件东西）；草坡上能看云和山的歇脚处（只看，呼应天空观察）。
- 带回物候选：溪边圆石、松果、掉落的羽毛——都不伤害自然（不建议采摘活花），带回后可以在院里自主安排，不消耗、不计数。
