# 探索「发现与获得」短展示：程序切片与资源契约（CURSOR-CLOUD，#153 / #155）

来源：用户经 GAME-PRODUCER 转达（[#155 5993470040](https://github.com/narutojzm1-dot/youjia/issues/155#issuecomment-5993470040)）。用户想要“类似在森林里拿到东西时的音效和展示效果”，要求先在近郊首片做出来，看人物透视、近远比例、遮挡、物件展示和声音是否协调，再决定后续场景。GAME-PM 衔接要求见 [#155 5993506217](https://github.com/narutojzm1-dot/youjia/issues/155#issuecomment-5993506217)。

借鉴的只是发现与获得的反馈感：不用现成游戏的音频，也不照搬演出。时长、位置、角色是否举物、音色都还没有获得用户批准，下面的数值都是可调整的候选。已决定的规则不变：单趟合计最多 3 件、可空手、随时回院、不设稀有度、成就或捡齐目标。

## 1. 玩家看到的流程（最小演示切片）

1. **发现**：沿路走到停留点、停下看。如果这里有东西，路边的物件下方出现静止的柔光地影（已有），字幕写「这里有一块圆石」。这一步不加音效、不闪烁，保持安静。
2. **获得**：点「带上」或「换成」，核心 `take` / `swap` 返回成功后才开始展示：
   - 人物做已有的拾起动作（`pickup`，0.6 秒）；
   - 物件从路边位置升到人物头顶上方（光晕下沿不压人物头部），停留展示，垫在一块带淡墨边和浅投影的圆形纸片上（白色落羽在繁复原画上也看得清），物件上方有一个纸色小标签写「圆石」；
   - 同时播放一声原创的短“获得”音；
   - 展示结束后，物件缩小飞进左下角提篮。篮子里的文字在核心接受时就已更新，与展示无关；第一版不做提篮跳动。
3. **继续**：展示期间玩家可以照常操作。走动、点「接着走」、按 R 回院、打开暂停都会让展示立即收尾（物件直接落进篮子），不会挡住输入，也不需要等它播完。走动和接着走时短音自然放完；暂停、失焦、回院和离开画卷时短音也立即停止，恢复后不补播（GAME-PRODUCER [PR #359](https://github.com/narutojzm1-dot/youjia/pull/359) 接入说明）。

存档和展示互不依赖：`take` / `swap` 成功时核心状态已经改变、记录已排进存档队列，展示只是表现。展示被打断、关页或回院都不影响带回结果；回院后的「收好了」仍以存档确认为准。

## 2. 触发规则（程序侧保证，并有隔离测试）

- 只有 `host.take()` / `host.swap()` 返回 `ok` 时才触发，每次成功只触发一次。
- 以下情况不触发：「放回」、`not_offered`、`carry_limit`、会话不在进行中、隔离冻结、按住键或连按造成的重复输入（展示进行时再按带上/放回，只按核心结果刷新，不再触发第二次展示）、恢复旧旅程、回院补交、存档确认。
- 换物只展示新拿到的那件；被换下的那件只是回到原处，不演出“获得”。
- 低动效（`ui.reduced_motion`）：不升起、不飞行、不缩放；物件在人物头顶上方同一位置静止淡入、停留约 0.6 秒，再淡出。音效照常播放（音量由玩家设置决定）。
- 静音或音效音量为 0：只有画面，流程完全一样。缺少音频资源时也一样，不用其他音效顶替。

## 3. 候选参数（实验值，等用户看过再调）

| 参数 | 候选值 | 说明 |
|---|---|---|
| 升起 | 0.35 秒，ease-out | 从路边物件位置到人物头顶上方一个光晕半径加 6 px；字幕可见时不高过字幕下沿，留出名字行 |
| 停留展示 | 0.9 秒 | 物件放大到约 72 px（1280×720 下的显示高度），光晕半径约 56 px |
| 飞进提篮 | 0.4 秒，ease-in | 缩到篮子里的尺寸 |
| 合计 | 约 1.65 秒 | 打断时立即收尾 |
| 低动效 | 静止淡入 0.3 秒 + 停留 0.6 秒 + 淡出 0.3 秒 | |
| 音效起点 | 与升起同时 | |

手机竖屏下展示位置跟随人物在屏幕上的实际位置，光晕和小字不越出安全区、不压底栏按钮。

## 4. 资源契约（GAME-PRODUCER 交付）

### 4.1 独立物件（圆石、松果、落羽）

- 格式：透明 PNG 母版，正方形画布，**1024×1024**；交付一张即可（1254×1254 也能接受，程序按比例缩放）。主体居中，四周至少留 8% 透明边，不带投影（地影由程序绘制，便于路边和展示两用）。
- 视角与光：与 `02_near_path` 原画同一水彩笔触和左上主光；略俯视、自然摆放的姿态。路边小尺寸和展示大尺寸共用这一张，所以缩到约 28 px 高时轮廓仍要认得出。
- 锚点：画布中心即物件视觉中心；程序在路边用“主体底部中点”贴地。请在 README 里写明主体包围盒（alpha ≥ 200 的像素），程序据此计算贴地点。
- 运行时副本：程序侧按需导出为 `assets/holiday/exploration/finds/<brook_stone|pine_cone|feather>.webp`（由 Cloud 在接入 PR 中完成），母版保留在 `art/concepts/` 的 Producer 交付目录里，附来源与 hash。
- 交付前程序仍用 `KeepsakeArt` 的代码占位画法；贴图到位后只替换绘制，触发与时序不变。

### 4.2 原创“获得”短音

- 一条：`exploration_find_get`，OGG Vorbis，48 kHz，单声道或立体声均可。
- 时长 0.6–1.2 秒，含自然尾音；开头 5 ms 内无爆音，结尾淡出到静音，总长不超过 1.5 秒。
- 电平：峰值不高于 −3 dBFS，响度与现有环境音乐同屏时不刺耳（建议 RMS 约 −20 到 −24 dBFS，最终以听验为准）。
- 气质：轻、暖、短的上行动机（例如木琴、钢片琴、拨弦或轻铃的两三个音），与悠长假期的安静陪伴一致；必须是原创，不使用、不模仿现成游戏的旋律或音色样本，并附生成或录制来源说明。
- 不要与鸭关注姿态或动物互动短音（#317）混用。
- 运行时副本：`assets/holiday/audio/exploration_find_get.ogg`（由 Cloud 在接入 PR 中放入，与现有院景音频同目录）。程序经 `SFX` 总线播放，遵守玩家的音效音量与静音；Web 上在第一次点击之后才会出声（已有解锁规则）。

### 4.3 暂不需要

- 角色举物姿势：先用已有拾起动作加上物件悬浮展示；用户看过后如果想要举起的姿势，再单独提出人物资源需求。
- “发现”音效：第一版不加，保持停下看时的安静；用户想要再加，同样走本契约格式。
- 清底底图、前景遮挡、相邻页仍按 #155 原范围另行交付，不阻塞本切片。

## 5. 程序侧实现与验证（Cloud）

- 文件：`scripts/exploration/find_reveal.gd`（新，展示节点，只负责画面与音效）、`scripts/exploration/near_path_scroll.gd`（成功拾起后调用；输入与回院时收尾）、`test/exploration_slice_suite.gd`（触发规则与打断）。不改核心、宿主、存档、`Main` 和 `AudioDirector`。
- 隔离测试：成功的带上与换物各触发一次；放回、停下看、空停留点不触发；展示期间走动、接着走、回院、暂停按钮会立即收尾，篮子状态与存档记录不受影响；低动效下没有位移或缩放；缺少音频资源时安静降级。篮满、未提供、恢复旧旅程、回院补交和 Esc 暂停不单独测试，由结构保证：展示只在 `pick()` 中 take/swap 成功后发起，Esc 暂停与失焦共用 `_notification` 收尾。
- 体验证据：桌面 1280×720 与手机 390×844 下的拾起帧序列、低动效对照；资源交付后补 Web 实玩与听感说明。用户看过首片演示后再定最终参数。
