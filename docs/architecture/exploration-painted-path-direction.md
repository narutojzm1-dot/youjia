# EXP-PAINTED-PATH：保留原画透视的探索

Agent-ID: GAME-PRODUCER。关联 #153 / #155 / PR322。2026-10-05 用户在本地制作人会话明确选择：**保留原画视角，沿路走动并自然换页**。此选择解决 [Cloud 提出的原画适配问题](https://github.com/narutojzm1-dot/youjia/issues/155#issuecomment-5990210307)。

## 已决体验

正式探索保留已确认绘画的纵深与透视。人物在画中道路上移动，在桥、林口等自然边界切到相邻画页。不要把单幅原画横向拉伸，不为迁就固定高度横走线重画或搬动世界。换页是同一世界的行走衔接，不是传送到无关风景。首片仍近郊＋圆石/松果/落羽，可停、可空手、可随时回院。

世界唯一空间基准是[扩大留白总图](../../art/concepts/producer_world_20261005/world_master_whitespace.png)，[七页标注](../../art/concepts/producer_world_20261005/world_seven_pages.png)仅供分片讨论。07 高处回望画面左院右村。七页非强制顺序，不因本次选择批准七页同时上线；远方留白不授权添加新地形。

## 首片可执行交接

CURSOR-CLOUD 继续拥有探索实现；制作人交原画、修订与玩法规格。PR322 现有 session/host、随时回院和提篮选择逻辑可按最新原单复用，不因表现变更重做可靠提交或建立第二份物品状态。本条不是对该 PR 代码/持久化的验收，公共存档仍按 Leader 边界协作。

以下是制作人建议的实现细化，需以实际取景和行走样张验证；不是用户另行确认了所有参数：

1. 以 `02_near_path.png` 原始 1672×941 坐标为资源基准，画内右侧院门与前景道路构成出门识别；溪流/桥为左侧世界地标。先标可走带与入口，不沿整幅水平线行走，不踩进溪水、岩壁、花丛或纸面留白。
2. 路径可用少量折线/曲线采样点描述，在表现适配器将路程映射为二维落脚点、朝向、遮挡和透视比例；核心仍消费 `visit/take/release/request_return`，无需从画内像素推断世界连接。路径、比例上下界及热点锚点由首片真实画面校准后存为资源元数据，不在此虚构数值。
3. 桌面优先展示完整构图；手机保证人物、正在互动的物件和回院入口可见，随人物平移但不走几步就变焦。画面不得非等比变形。低动效保留行走/交互可读性，用静态切页而非强制镜头演出；暂停、界面打开与失焦应停止输入。
4. 入口/出口需按总图核对两侧对应地标，进新页后的落脚点和朝向能解释来路。不将七页编号直接连成 01→02→03→04→05→06→07；未交付的页不摆一个会困住玩家的可进入出口。首片回院动作一直可用。
5. 02 底图已画有松果、落羽等图案。正式采集精灵需独立资源与清底，避免带走后留下同一物件副本。图包仍是候选，清底不得改变道路、院门、桥溪等空间锚点；摄影/旧资源路径兼容单独验证。

## 不由本次决定推出

携带上限、出现频率/掉率、提篮尺寸/位置、精确触屏手势、远处重访入口、全部跨页邻接边和转场时长尚未冻结。原型中的 1 件上限、4 个停留点、3600×720 画卷不是用户批准数值。先沿已决体验做近郊可玩切片，不能把这些未决数值包装成已批准产品约束。

## 适用验收

- 同一截图中人物脚点落在道路，可见人物朝向与实际移动一致；近远变化和遮挡不破坏原画比例，无侧滑穿景。
- 桌面横屏和 390×844 竖屏实际输入下可走、可停、可看物、可放回、可随时回院；不把模拟视口当手机真机。
- 切页往返方向和地标连续；低动效、暂停/恢复、失焦、窗口变化无输入残留或人物丢出视口。
- 原画没有被拉伸或重复拼接；物件带上/放回与当前旅程状态对应，空手回院不出现失败压力。
- 存档与写入失败沿既有可靠接口验证，不能把内存成功当落盘；按最终 SHA 独审及实际导出/体验证据交付。
