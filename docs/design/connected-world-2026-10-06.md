# 有关联的小院与外界

来源：用户 2026-10-06 在本地 Leader 会话明确提出的新方向。Owner：CODEX-LEAD，兼制作人。总单 [#503](https://github.com/narutojzm1-dot/youjia/issues/503)。**方向已确认，以下系统尚未实现，不能当成当前游戏能力。**

## 玩家要感受到什么

世界继续朝更有趣、更有关联、更多彩蛋、更丰富发展。小院里的行为可以改变谁来到院门、谁一起出门；同行者发现人独自看不见的东西；新的发现和伙伴回到小院，又产生新的关系和故事。日常行为相互影响，玩家可以留心、试一试，也可以错过后再遇见。

## 已确认的玩法与故事

1. **大背篓与随身携带贯通。** 小院有大背篓，外出所得回院进入其中，可以通过 UI 打开查看。钓到的鱼也能存入，再取出丢到地上给动物吃。背包/仓储功能服务于可看见的物品和互动，不靠额外经济压力推进。
2. **地面食物是真实对象。** 草不再只能立即定向喂羊驼：丢到地上形成掉落状态，牛、羊和羊驼能自行接近并吃。丢在两个动物中间，最后谁吃不确定；一次食物不能被两只动物重复消费。鱼也沿用地面投放机制，按动物食性选择接受者。
3. **吸引与跟随有个性。** 牛吃到一把草不会就变成跟班，要在院门附近陆续放草，让它因食物靠近。羊驼可用绳牵出小院。玩家出门时，恰好在附近的动物有概率同行，并在院外跟随。出门/回院/中断恢复必须保留动物身份，不复制或丢失伙伴。
4. **同行者打开另一层发现。** 部分隐藏物只有动物能翻出来，之后人才看见和拾取；需要可感知的嗅闻、刨动、翻找等过程，不只是背包突然加物品。不要求每次外出都带动物，也不使普通独行探索失效。
5. **beibei。** 村落较近的一张地图有一只白色流浪奶狗，名为 `beibei`；带回养大后可以随行，发现更有趣的东西。用户原话“白色狮子流浪奶狗”，暂按“小狮子般蓬松的白色幼犬”理解，未锁定品种或具体参考。成长速度、阶段及触发条件在切片设计时明确，不加入因玩家没上线而受苦的照料压力。
6. **乌龟—鸡—鹅的关系链。** beibei 在水边发现/揪出一只乌龟，后来住进小院池塘；那时已经长大的鸡与它很亲近，乌龟会驮鸡玩。大鹅也想骑，乌龟不肯，于是鹅见它出来会想啄。保留用户指定的区别对待与小脾气，用动作和回避演成轻喜剧；不自行扩大成战斗、伤害或死亡系统。
7. **鸡与小米。** 小鸡吃小米，并有成长为鸡的过程；小米可以作为投地后啄食的食物。来源与具体获得方式需贴合山脚村落，不能把尚未确认的野生植物采集写成事实。

## 已有实现与迁移边界

- `SaveStore.get_keepsakes()` 和 `request_exploration_trip()` 已保存探索所得与旅程水位线；后者在同一提交中写入所得、记录与序号。复用这一持久化基础，不能另建一个 UI 私有背包来重复记账。
- `YardWorld` 现有鱼是携带类型与计时状态，并非已持久化的大背篓库存；新规则会改变这部分，需要迁移设计和 #231 鱼状态回归。已经入篓的鱼不得仍被旧手持计时器误删，旧手持状态也不能凭空迁成多条鱼。
- 草的旧定向递食动作是已交付实现，但**未来玩法以本次地面投放授权为准**。保留仍适用的美术资源，逐片替换交互语义，提示必须说清“丢下”与“喂给”区别。
- 同一物品在随身、院内背篓、地面、被消费之间转移时必须数量守恒；新 schema、未知字段、失败/未知提交、重复点击、多页写入必须走现有可靠保存门禁。物品视图不得先显示成功再忽略落盘失败。
- 动物同行/成长/剧情用稳定身份和世界状态；活体伙伴不当成普通可堆叠物。乌龟带回池塘是安置事件，不自动推出任意动物交易或通用捕捉系统。
- 新角色、地面食物和关系动作另有资源需求，按同角色完整画作、锚点、原尺寸场景、Web预算与来源记录验收；缺资源不冒正式完成。

## 小米与阿尔卑斯语境查证

中文小米通常指粟的去壳籽粒，植物为 **Setaria italica**（foxtail millet，德语 Kolbenhirse）。瑞士 ProSpecieRara 的栽培作物名录列有该种，其实际保种页面也展示 Wildegg 城堡花园的 Kolbenhirse。因而“山脚村落种植/储存的谷物或鸡食”是有现实依据的设计解释；这些资料**不能证明它是阿尔卑斯高海拔野生植物**。不要把另一种黍 Panicum miliaceum 的种植资料直接当成粟的证据。

- [ProSpecieRara 栽培物种名录（2015版）](https://cms.prospecierara.ch/assets/website/prospecierara.ch/Pflanzen/Wissen/ProSpecieRara-Art-Liste.pdf)：Kolbenhirse / Setaria italica。
- [ProSpecieRara 保种与花园实例](https://www.prospecierara.ch/pflanzen/ackerpflanzen/sortenerhalterin-werden)：Wildegg 花园种植实例。

以上用于游戏世界设定，不把单一谷物写成现实幼鸡的完整饲养配方。当前先采用“村落谷物/鸡食中有小米”的方向，具体取得过程随村落内容设计。
