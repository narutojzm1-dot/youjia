# 同行切片实施边界（待实现）

CODEX-LEAD，#503 的 C 切片。以下是接续 PR508 后的实施方案，不是已上线能力；总方向见 connected-world-2026-10-06.md。

## 一个完整往返

在实际出院小路前发起出门时，读取同一 YardWorld 中稳定的动物 actor_id。绳牵草泥马保证同行；未牵绳时，仅考虑玩家附近的陆行动物，每趟最多一个自愿伙伴。先以 120 院内像素、35% 概率作为可调体验参数，选择只在创建该旅程时执行一次，不在每帧、点击重试或恢复时重抽。普通独行仍完整可玩。鸭留在池塘，暂不扩大到水禽离池系统。

伙伴沿 NearPathLayout 已交付道路跟随，保持人物与动物的透视、脚点、遮挡和停步关系；绳牵草泥马显示连到人物手部与项圈的绳。不能直接套院内 roam 范围让动物穿过溪流。复用完整角色画与既有步态，不把方块或文字名牌当正式同行效果。

正常回院返回同一 YardWorld 的同一 actor_id，回到玩家附近合法脚点；标题、重开、异常恢复按现有探索契约安全回院。不能把伙伴记作可堆叠背篓物品，也不创建第二只常驻动物。暂停/失焦/低动效仍可结束旅程。

## 需落实的接口

- YardSceneHotspots/YardInteraction：显式院门点击允许绳牵出院，仍保留松绳操作；普通环境观察不抢走牵绳意图。Main 的 _on_exploration_requested 采集候选与当前绳牵身份。
- ExplorationSession/Contract：可验证的同行身份随旅程记录冻结；兼容没有同行字段的旧记录，坏值不能静默变成另一只动物。Host.begin 与 Director.try_begin 传递上下文，不让 NearPathScroll 自己随机选伙伴。
- SaveStore/Coordinator：同一出发记录携带选择结果；明确处理尚未确认、被拒、未知、重复点击和跨页写入。身份和返程不以额外独立库存写入维持，避免半次移动。
- NearPathScroll：独立同行表现组件，复用道路坐标与角色资源；不让表现组件直接改 session。返回时由 Director/Main 恢复院内对象。
- 回院未提交所得或恢复中断的路径必须一并覆盖。不能只测普通返回按钮。

## 验收与下一步

原生验证旧档、抽签稳定性、绳牵必随、范围/物种过滤、暂停/返回/标题/重启、保存拒绝和未知结果、不重复伙伴。真实 Web 输入走通绳牵出院—走路—停下—回院，另测门口草堆把牛引近后可能同行，桌面及手机都有画面与动作证据。
