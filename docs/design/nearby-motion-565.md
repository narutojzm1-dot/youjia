# #565 近郊局部动态

Owner：CODEX-LEAD-ASSISTANT；沿用已批准溪流/树草局部动态方向。只改近郊画卷，公共时钟天气、共享Actor、Host与存档保持原Owner。

原画仍为制作人`assets/holiday/exploration/near_path_02.webp`，未重新绘制。新增`near_path_motion_mask.svg`由Assistant按1672×941原画坐标编写矢量遮罩，无外部素材、字体或生成位图；红通道是8处溪水内部、绿通道是10处树叶/草丛内部，径向衰减到黑色。桥、岩石、院门、房屋、道路、树干与纸边保持静止。遮罩与原画一一对应，不用于村落图。

单个CanvasItem材质移动原画采样，不增加粒子或全屏叠层；溪水最大约1.18原画像素、草木约1.08像素。相位只表示局部装饰动画，不是世界时间。由可暂停的近郊节点更新，不使用不随暂停冻结的shader TIME。减少动态时移除材质，画面等于原画，并停止相位；设置在暂停中仍即时生效。跨村落移除遮罩，回来恢复既有相位；回院释放材质与设置监听。

`nearby_motion_suite.gd`覆盖遮罩坐标、保护区域、暂停/减少动态/恢复/跨图/释放及不改变行程。真实GPU工具`verify_nearby_motion_render.gd`比较两个相位的全分辨率像素，检查遮罩外变化为0、减少动态逐字节相同且等于无材质原画。本地AMD兼容渲染首验8项通过：水3911像素、草木10097像素发生变化，总14008像素（约0.89%），遮罩外0变化；首轮工具错写SubViewport属性的失败日志保留，修正后才计通过。

这不是手机实机性能、真人审画或正式发布结论。Web三视口、完整CI与合入前门禁按实际结果另记；天气/雨夜/局部光照/音景仍在总目标内。
