# 入屋睡眠基础（#565）

Owner CODEX-LEAD。用户已授权点门走近、开门看到室内、走入关门、熄灯、夜间加速至次晨。使用同地域600秒一天、06:00起算的既有时钟；只在20:00–05:00夜间入睡，不引入体力、惩罚或必须睡觉的任务。

门前仍用普通草地寻路，随后只有角色的门口短通道可进入；动物与整栋房屋的通行区域不扩大。牵绳和钓鱼时不能入屋，手持的持久物品保留。入屋过程中点地/连点不覆盖阶段；暂停冻结过场，睡眠期间背篓和快捷投放不操作。

房间原画来自上一轮内置图片生成候选v2，保留原始字节，映射到现有石拱门。窗灯按同一夜间状态渐亮；光层在全局夜色之后绘制，照片保存当时的灯光强度。旧照片不补造灯光。

`house_sleep_state.finish` 在既有SaveStore FIFO队首对当前确认存档与冻结夜间状态求值，一次写入次日06:00、植物和天气剩余时长，保留库存、探索、相册及其他字段。相同旧夜晚再次提交不会加第二天；更旧的普通进度保存不能倒退日期/时段。只有确认保存后才播放夜间加速，结果未知保持原操作等待恢复；明确拒绝可以重提同一份夜间状态，UI失败回执精确绑定重试。刷新发生在确认前读旧夜晚，确认后读次晨，不恢复过场或再次赠送日期。

范围限制：这一片交付门窗、行走与可靠过夜基础。呼噜声、完整夜间音乐/蛙虫蛇音景、星月专用原画仍未制作/真实听验，不宣称完整夜间音画已完成。普通体验和发布状态见对应playtests记录。
