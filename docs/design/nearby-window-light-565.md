# 近郊屋窗夜灯（#565）

Owner：CODEX-LEAD-ASSISTANT。原单范围回执：#565 / issuecomment-6104344807。

原近郊已有公共昼夜乘色，院落的窗灯层仅在院落画面显示，远处屋窗在近郊夜间仍保持原画的暗玻璃。本片复用 `HouseLights.wants_light(day_fraction, false)`：20:00—次日05:00，旅人处于室外时保留暖窗。只消费现有 `environment_snapshot`，不创建新时钟、室内状态或存档字段。

在原画坐标 `(1345,312,170,112)` 内建立18个小玻璃掩膜。保持窗框、十字隔条、花箱和门洞不着色；夜灯独立世界坐标 CanvasLayer 6，位于公共昼夜乘色层5之后、近郊HUD层8之前。随原画全局变换和现有镜头移动，不替换水/草动态材质。单个掩膜76,160解码字节、绘制19,040像素，不复制整张背景。

普通模式只缓慢改变灯光透明度；减少动态效果时保留静态夜灯，立即落到公共时间对应亮度。实际SceneTree暂停冻结渐变；村落切页隐藏原近郊窗灯，返院释放本地CanvasLayer。重新进入近郊时同步当前公共时间，避免白天显示切页前的夜灯。

本地验证：`nearby_window_light_suite.gd` 29项通过，覆盖公共规则、只读状态、暂停/偏好、换页/清理。`verify_near_window_light_render.gd` 在AMD 8060S真实OpenGL渲染18项通过：1672×941、1280×720、390×844三种现有镜头，分别1204/564/667个像素变亮，双线性掩膜支持外改动为0；窗框不变，白天与无灯底画字节一致，减少动态效果保留相同静态夜灯。

这些GPU画面使用受控公共时间快照，只验证像素和变换。普通流程的自然夜晚、最终SHA CI、Web导出及公开发布核验仍须另记；未在此冒称正式版或真机手机验收。初版测试缺显式Dictionary类型及加载脚本时机不正确的失败日志保留在接续目录，后续29项通过日志单独保存。

文件边界：仅近郊局部灯光、玻璃掩膜、NearPathScroll既有环境同步入口及本片测试。共享Actor、Main、Host/Inventory、音频及整体UI不变；Leader #623真实音频验收保持独立。
