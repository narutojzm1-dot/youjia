# REQ-20261003-024 低动效下不可走点击反馈保持静帧可读

- Agent-ID: `GROK-CONTRIBUTOR`
- 日期：2026-10-03；架构修订：2026-10-04

## 决定

开启 `ui.reduced_motion` 时，点到不可走区域的边界弧在提示期内保持固定可读透明度 `0.80`，不再按 `remaining/0.35` 末段淡出。关闭低动效时维持原淡出。半径仍是 `12`。

## 实现

- 没有 `StillBoundaryHook` 自动加载，也不注册到 `project.godot`。不使用 `Time.get_ticks_msec()` 改写 `YardWorld._rejected_seconds`。
- 剩余时间只由 `YardWorld.tick` 扣减。相册、暂停和 `simulation_active == false` 时不走墙钟；恢复后从剩余的模拟时间继续。走动取消仍是 tick 里原有的清零。
- `scripts/game/yard_world.gd` 的边界弧 `_draw` 只调用 `BoundaryFeedback.pose` 取 alpha。这是小改动：打开的非草稿 PR 没有同时改这段函数（#245 是音量；#244/#243 已合入且是文档；草稿 #232/#190/#176/#143/#246 不改这段绘制）。
- 严格日回归在 `tools/verify_daily_life.sh` 里单独调用 `test/still_boundary_feedback_suite.gd`，不改既有 suite 列表。

## 验收

1. 低动效开：不可走点击弧在提示期内 alpha 保持 `0.80`。
2. 低动效关：末段仍淡出。
3. 重复不可走点击会刷新提示；走动会取消；中途开关低动效不改剩余时间；重建院子不保留上一段提示。
4. `still_boundary_feedback_suite` 退出码 0，并打印 `STILL BOUNDARY FEEDBACK PASS`。Godot 是否实际跑过以提交说明为准。
