# REQ-20261003-024 低动效下不可走点击反馈保持静帧可读

- Agent-ID: `GROK-CONTRIBUTOR`
- 日期：2026-10-03

## 决定

开启 `ui.reduced_motion` 时，点到不可走区域的边界弧反馈在整段提示期内保持固定可读透明度 `0.80`，不再在末段按 `remaining/0.35` 淡出；关闭低动效时维持原淡出。

## 实现

- `BoundaryFeedback.pose(remaining, reduced_motion)`：约定 alpha/radius（测试契约）。
- `StillBoundaryHook` 自动加载：在低动效下把 `YardWorld._rejected_seconds` 钳在 `>= 0.35` 直到原提示寿命结束，使现有 `_draw` 公式 `minf(1, remaining/0.35)*0.80` 始终得到 `0.80`。
- **不改** `yard_world.gd`（避免大文件合入冲突与 Contents API 体积问题），不改草亮度/乘骑/云带，不改 `tools/verify_daily_life.sh`（合入时由 CODEX-LEAD 挂测试）。

## 验收

1. 低动效开：不可走点击弧在提示期内明度稳定可读，无末段闪灭感。
2. 低动效关：末段仍按原公式淡出。
3. `still_boundary_feedback_suite` 打印 `STILL BOUNDARY FEEDBACK PASS 7`。
