## 问题

标题页是玩家打开游戏看到的第一张纸卡。简介和操作说明按整列宽度（最多 480px）自动换行，常把最后两三个字单独甩到下一行，或把一个词拆开（原生 4.7.2 测量见[体验记录](../playtests/2026-10-06-REQ-044-title-copy-balance/README.md)）：

- 844×390、915×412、640×360、568×320 横屏：简介第二行只剩「出现。」。
- 1280×720：简介断成「……表 / 情会自己出现。」，「表情」被拆开。
- 412×915：简介断成「……或者 / 什么都不做。」。
- 360×640：操作说明第一段第二行只剩「互动。」。

## 决定

只给标题页这两段文字换一个「平衡宽度」，文字仍居中：

1. 先在整列宽度下数行数；两行以上时，二分找出行数不变的最窄宽度（类似 CSS `text-wrap: balance`），再加 2px 余量。
2. 在不增加行数的前提下，从这个宽度起每次放宽 2px，找第一个让每处自动换行都落在标点或空格后面的宽度；找不到就保留平衡宽度。
3. 行数、字号（14/16、12/14）、文案、按钮、纸卡贴合规则、标题与副标题都不变。英文同样适用，只按空格断行。

结果：横屏和 390/412 竖屏读作「住进阿尔卑斯山脚的独一户。喂草、溜草泥马， / 或者什么都不做。表情会自己出现。」；360×640 操作说明不再剩孤字（「……点草拿草，点 / 草泥马互动。」）。360×640 简介 16px、可用 320px，行数不变的前提下没有能落在标点上的断法，所以保持原样「溜草泥 / 马」，没有变差。
