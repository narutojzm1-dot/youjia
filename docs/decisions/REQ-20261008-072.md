## 问题

在院子南边小路（`PATH_POINT` 300,620）静站 2.5 秒，会出现一只小蜗牛和一株三叶草（REQ-20261003-021 的原画），停 3.2 秒后收起。现在两张画第一帧就是全不透明（直接蹦到草地上），3.2 秒一到又在一帧内整块消失。同一个 `YardSceneFeedback` 里的其他院景回应（窗台花瓣 / 蝴蝶、岸边涟漪 / 蜻蜓、篱边草叶 / 落羽）收尾时都会在最后约 0.35–0.46 秒淡出，只有这一对硬切；而它恰恰是「静静站着才出现」的安静发现，一帧蹦出最显突兀。

## 决定

- 普通动效：蜗牛和三叶草出现后 0.3 秒从透明淡到全显（`PATH_FADE_IN`），3.2 秒停留的最后 0.35 秒淡出到透明（`PATH_FADE_OUT`，与其他院景回应同量级）；两张画始终同一透明度。
- 新增 `path_alpha()` 读当前透明度，供测试与以后需要的地方用。
- 走开：照旧在迈步那一帧立即收起（与其他院景回应一致——走动意图本就会 `cancel()` 全部院景回应），不改。
- 低动效：照旧一出现就全显、到时直接收起，不加任何渐变。
- 不改：静站 2.5 秒触发、3.2 秒停留、14 秒间隔、位置、缩放、原画、层级、`cancel()`、不写相册、`yard_world.gd`。
