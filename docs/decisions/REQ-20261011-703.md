## 问题

## 决定

- 新增 `scripts/presentation/resident_barks.gd`：文案目录、全局/按 id 冷却、小鸡偶发概率、疲劳门闩（`fatigue_active` 必须由外部传入）。

- 不改 SaveStore/codec/Host、作物模型、行动点、面板布局、近郊导演。
