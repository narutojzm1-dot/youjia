# REQ-20261006-040 暂停页音量滑条换成暖纸样式

- 日期：2026-10-06

- 基线：main `49596fa93bff3c29edfe441898017158c6e469a3`（问题渲染在前一个 main `b300da7` 上，暂停页代码两者相同）

## 问题

暂停页「音乐音量」「环境音量」两条滑条是整块暖纸面板上唯一没套主题的控件，用的是 Godot 默认样式（main `b300da7` 原生 4.7.2 渲染，390×844 / 844×390 / 640×300 均可见）：

- 轨道是冷灰条，像被禁用的控件；
- 已填部分是浅灰、未填部分反而是深灰，读起来方向是反的（40% 时看上去像剩 60%）；
- 手柄是一个约 16px 的近白小点，压在浅灰轨道上几乎看不见。

## 决定

新增 `scripts/ui/paper_slider_style.gd`（`PaperSliderStyle.apply(slider)`）和自动加载 `autoload/paper_slider_boot.gd`：后者与现有 `ManusFontTheme` 同一做法，在节点进树（`node_added`）时给每个 `HSlider` 套样式；`project.godot` 只在 `WebHiDpiBoot` 后加一行 `PaperSliderBoot`。**不改 `scripts/main.gd`**——#382（输入路由）和 #459（焦点路径）都在改那个文件，这样不会和它们撞车。目前游戏里只有这两条 HSlider。

- 未填轨道：浅暖纸 `#eadcc8`，1px 柔棕边 `#9c7f68`（对 PAPER 3.47:1），高 8px，两端圆角。
- 已填部分：深杏色 `#a85d28`（与标题强调色同色，对 PAPER 4.6:1，对未填轨道 ≥3:1）；悬停 `#94501f`。
- 手柄：24px 奶油圆盘 `#fffaf1` + 2.5px 深杏圆环；悬停/拖动时底 `#ffe7c8`、圆环变墨色 `#5b4637`；禁用态浅暖纸 + `#bfa588`（滑条目前不会禁用，只是补齐）。
- 手柄用 `DPITexture`（SVG）生成，Web HiDPI 提高 `content_scale_factor`（REQ-20261005-026）时仍清晰，不新增图片资源。

## 不做

- 不改滑条的取值范围、步长、默认值、尺寸（`custom_minimum_size` 仍 120×28/32，命中矩形不变）、`focus_mode`、`mouse_filter`、信号连接、音量增益或 AudioDirector。
- 不改 `scripts/main.gd`；不碰 `Main._input`、`_drag_volume_slider`、`_point_sets_slider`、`_fit_pause_panel`、确认层路由（#382 Assistant 在途）。
- 不覆盖滑条 `focus` 样式（键盘焦点路径归 #459 Assistant），保持引擎默认。
- 不碰 `scripts/ui/photo_arrival.gd`（#461）、标题页、通知、相册、存档、探索。
- 不改 `tools/verify_daily_life.sh`、`tools/lib/godot_suite_completions.tsv`、`docs/requirements.md`；登记行见文末，交合入方。
- 只是原生验证，不冒真实浏览器 / DPR / 触屏 / 手机验收。
