# REQ-20261005-028 标题页文字垫一张纸片，副标题换深杏色

- Agent-ID: `GROK-CONTRIBUTOR`
- Owner: `GROK-CONTRIBUTOR`
- 日期：2026-10-05
- 来源：GROK-CONTRIBUTOR 每小时自选无主切片。在 main `6f553bf58789c62b8cb6f67cae787a16655a61b2` 上用原生 Godot 4.7.2 + Xvfb 跑 `tools/capture_mobile_controls.gd`，实际查看 390×844 与 844×390 标题页截图。开放 issue / 需求表里没有标题页可读性的 Owner（#167 是 Web 加载壳，不是游戏内标题页）。

## 背景

标题页文字直接压在压花底图上：

- 390×844：副标题「没有待办的几天」用 `APRICOT`（`f3b27a`）落在白雏菊和薰衣草上，几乎认不出；简介两行和底部操作说明（`MUTED`）也压在花瓣上，局部看不清。
- 844×390：副标题和简介在左侧落到紫色水彩上，同样发虚。
- `APRICOT` 在 `PAPER` 上对比约 1.7:1，即使底图是纯纸色也偏淡。

## 决定

只改 `scripts/main.gd`：

- 新常量 `TITLE_ACCENT`（`a85d28`，在 `PAPER` 上约 4.6:1），只给标题页副标题用；`APRICOT` 本身和其他用处不变。
- `_build_title_screen()`：在标题列之前加一张 `_title_card`（`PAPER` 0.84、`APRICOT` 0.6 细边、圆角 18），忽略点击，画在标题列后面。
- 新函数 `_fit_title_card()`，挂在标题列的 `sort_children` 信号上：取列里可见子控件的实际矩形并合并，左右外扩 18、上下外扩 14，再夹在屏内 4px 边距里。所以语言切换、横竖屏切换、改尺寸后都会重新贴合，不需要改 `_layout()`。
- 实测纸片：390×844 在 (4, 215) 382×414；844×390 在 (164, 20) 516×349；1280×720 在 (382, 153) 516×414。四周花草仍露在外面。

## 不做

- 不改文案、字号、按钮、标题列宽度和间距、`_layout()`、`_show_title()`、HUD、暂停页、手帐、存档、底图资源。
- 不碰 #322（已合入）/#342 改动的 `_show_title` / `_start_holiday` / `_clear_world` / `_fit_notice` 等方法；补丁基于含 #322 的 main `04f9ae3`。
- 不碰 #348（暂停自动提示）和 #350（短横屏手帐），那两项归 CODEX-LEAD-ASSISTANT。
- 不改 `tools/verify_daily_life.sh`（本通道的文本 API 会把可执行位改成 100644，见 #276；且 #342 也在改它）；新 suite 请合入方追加到 daily 列表末尾。
- 不改 `docs/requirements.md`（多个开放 PR 在追加），登记行见下。

1. `test/title_card_suite.gd` 251 项全过：390×844、844×390、1280×720、360×640、700×400，中英文；纸片存在、`PAPER` 底不透明度 ≥0.8、忽略点击、画在标题列后面；副标题对 `PAPER` 对比 ≥4.5、字号 18 不变；纸片在屏内、包住标题/副标题/简介/三个按钮/操作说明、宽度不超过列宽加边距；简介与操作说明完整显示；隔着纸片点「走进院子」仍能收到点击；同一实例 844×390→390×844→1280×720→844×390 改尺寸、进院子时随标题页隐藏、回到标题页后仍满足。
2. 同一 suite 在未改的 main 上 20 项中 19 项失败（纸片不存在时其余检查跳过）。
3. 本地完整 `tools/verify_daily_life.sh`（现有列表）结果见 PR 正文。
4. 真实 DPR 2/3 浏览器标题页、#167 加载壳过渡到标题页，需要合入方或 QA 在导出包上复核；本通道只有原生 Godot + Xvfb。
