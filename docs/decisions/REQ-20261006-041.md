## 问题

院子里用鼠标悬停「翻开手帐」按钮时，会弹出提示「点此打开拍立得手帐」/ "Open the polaroid journal"（`hud.album.tooltip`）。这个提示用的是 Godot 默认的 TooltipPanel / TooltipLabel：

- 底是半透明黑（alpha 0.5），盖在奶油色 HUD 和按钮上像一块灰色污渍；
- 字是浅灰 `0.875`，叠在奶油底上的半透明黑上约 3.2:1，不到 4.5:1；
- 它是暖纸 UI 里最后一个没套主题的弹出层（原生 4.7.2 + Xvfb 真实悬停截图可见，见[体验记录](../playtests/2026-10-06-REQ-041-tooltip-paper/README.md)）。

## 决定

新增 `scripts/ui/paper_tooltip_style.gd`（`apply(theme)`），由 `autoload/manus_font_theme.gd` 在建好共享运行时 Theme 后调用一次（+3 行）。这个 Theme 本来就挂在每个根 Control 上，提示弹层的父节点就是悬停的按钮，提示里的 Label 也会拿到这个 Theme，所以不用改 `scripts/main.gd`，也不用改 `project.godot`。

- TooltipPanel：PAPER `#fff6e8` α0.97 近不透明暖纸，1px 柔棕边 `#9c7f68`（对 PAPER 3.47:1），圆角 8，内边距 10/5，淡墨阴影（`#5b4637` α0.18，4px，下移 2px）。
- TooltipLabel：字色 INK `#5b4637`（对纸底 7.7–8.3:1，按下面垫黑/白/奶油/草绿算），去掉阴影和描边。字号、字体不变。

## 不做

- 不改 `scripts/main.gd`（#382 / modal-touch 在改）、`project.godot`、#466 的滑条自动加载、`scripts/ui/photo_arrival.gd`、探索（#467/#375）、存档。
