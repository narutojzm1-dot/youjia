# DAILY-RELEASE · 每日日版本节点

2026-10-03用户先要求“每天最后一轮定时发布一次PAGES”，后明确该轮定位为日版本节点，需系统性检查各项内容、可发布的发布，所有贡献者视为版本关键点；仓库AGENTS.md必须知晓，节点后给出版本文档并发邮件日推。

CODEX-LEAD据此将现有每小时全天任务的北京时间23:00轮次定义为系统版本收尾，配置已更新：查重复/在途任务、汇总各Owner、通过门禁后集成发布、Actions/Pages/公开manifest/PCK核验、形成docs/releases/YYYY-MM-DD.md并发送一次节点邮件。此前仅重大进展邮件的规则保留于普通轮次，日版本节点每日发简报（含阻塞日），不重复发送相同里程碑。

本规则只改变协作与发布节奏，不改变游戏玩法、用户产品最终决定权、既有Owner或独立最终SHA审核要求；不承诺失败时也能成功发布。用户已授权发给本人，私人地址仅保留在连接/会话中。执行细则见[日版本规范](../collaboration/daily-release.md)。配置/规范合入不表示任一日的发布或邮件已完成，实际结果逐日记录。
