## 问题

拍到新照片时，相片在 0.2 秒内淡入，但上方那行「旅人随手拍下了这一刻。」/ "The traveler caught this little moment." 连同它的小纸签在第一帧就以全不透明出现。结果是字先“啪”地压在院子上，相片才慢慢浮出来，像两件东西前后跳出来，而不是一张相片连着它的题注一起到来。

## 决定

- 普通动效下，题注行（纸签是它的子节点，跟着它走）与相片**同一时间、同一时长**淡入：都从 0 到 1，0.2 秒（新常量 `ARRIVE_FADE`，与相片原有淡入时长一致）。
- 之后的停留 1.1 秒、相片 0.28 秒 / 题注 0.24 秒淡出、1.58 秒截止、只完成一次，全部不变。
- 低动效：相片和题注照旧一出来就是全不透明，不淡入。
- 淡入途中切到低动效：相片和题注立即全显，按原截止时间收起（沿用原有切换逻辑）。
- 新相片顶掉正在淡出的旧相片时，题注从 0 重新淡入，不残留上一张的透明度。
- 不改：相片 / 题注 / 纸签的位置、大小、字号、配色、文字、窄屏适配，`main.gd`、相册、拍照判定、存档。
