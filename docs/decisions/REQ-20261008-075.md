## 问题

玩家从背篓取出中鱼后，界面写着「手里拿着：中鱼」，回到院子却几乎看不出手上有东西；进「把小物摆在院里」独立面板又看不到鱼（#594 / #597）。用户要 Minecraft 式底部横排快捷栏，并取消独立摆放面板、支持直接拖或「选中后点地」。

## 决定（本片范围）

- **新建** `scripts/ui/hold_hotbar.gd`：水彩纸底、五格（小鱼 / 中鱼 / 怪鱼 / 草束 / 小米），图标与背篓同资源；`update_view(inventory, …)` 只读真实 `yard_inventory`（held + 计数），手持格强制可见且选中；点手持格切换「点地投放」武装；空手点有货格发出 `withdraw_requested`（交给既有 `YardInventoryController.request("withdraw")`）；忙时禁用。触屏 `press_at`。`preferred_rect` 给合入方贴在底部芯片行上方。
- **新建** `scripts/inventory/hold_place_intent.gd`（纯函数）：`food_drop_at` / `food_drop_near_player` → 可交给 `request("drop", kind, {x,y})` 的参数；`decor_place_at` → 可交给 `YardDecorController.request("place", spot, …)`；非法 / 空手 / 无库存返回 `error`，**不改快照、不扣数**。`would_commit_food_drop` 用既有 `YardInventory.transition` 证明合法才推进 revision。
- **不**另建第二套库存；不整文件改写 `main.gd` / `yard_world.gd` / 背篓或布置面板（开放 PR #600/#542/#592/#579/#578/#576 占用）。
- **本片 OUT**：Main 挂载与 `_layout`、院子点地路由、取消独立布置面板、背篓拖出落地、多格快捷栏切换手持的完整事务编排、键盘 1–5。由 Leader 共享事务兜底 + 后续片接；与 Cursor #595/#598 方法重叠处协调。
