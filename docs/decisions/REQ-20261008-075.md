## 问题

玩家从背篓取出中鱼后，界面写着「手里拿着：中鱼」，回到院子却几乎看不出手上有东西；进「把小物摆在院里」独立面板又看不到鱼（#594 / #597）。用户要 Minecraft 式底部横排快捷栏，并取消独立摆放面板、支持直接拖或「选中后点地」。

## 决定（本片范围）

- **新建** `scripts/ui/hold_hotbar.gd`：水彩纸底、五格（小鱼 / 中鱼 / 怪鱼 / 草束 / 小米），图标与背篓同资源；`update_view(inventory, …)` 只读真实 `yard_inventory`（held + 计数），手持格强制可见且选中；点手持格切换「点地投放」武装；空手点有货格发出 `withdraw_requested`（交给既有 `YardInventoryController.request("withdraw")`）；忙时禁用。触屏 `press_at`。`preferred_rect` 贴在底部芯片行上方。
- **新建** `scripts/inventory/hold_place_intent.gd`（纯函数）：`food_drop_at` / `food_drop_near_player` → 可交给 `request("drop", kind, {x,y})` 的参数；`decor_place_at` → 可交给 `YardDecorController.request("place", spot, …)`；非法 / 空手 / 无库存返回 `error`，**不改快照、不扣数**。`would_commit_food_drop` 用既有 `YardInventory.transition` 证明合法才推进 revision。
- **Main 挂载（本修订，CODEX-LEAD #601 评论要求同一 Owner 完成）**：
  - `_ensure_hold_hotbar`：在 `_ui_layer` 创建 HoldHotbar（背篓旁）
  - `_on_inventory_changed`：与背篓一并 `update_view`
  - `withdraw_requested` → `_on_hold_withdraw` → `_inventory.request("withdraw", kind)`
  - 武装时院子点地：`_try_hold_place_at` → `HoldPlaceIntent.food_drop_at(held, world, physical_obstacles("player"))`；成功 `request("drop", …)`；非法只 `notice.cannot_walk`，**不扣数**
  - `_layout_hold_hotbar` 用 `preferred_rect`；`_sync_hold_hotbar_visibility` 仅开院可见，暂停 / 相册 / 确认 / 背篓 / 布置时隐藏
- **不**另建第二套库存；不整文件改写 `main.gd`；不改 `yard_world` shelter/resident（#600 / #565 Leader 范围）。
