## 问题

院子底部的纸签通知（钓空、空闲引导、天气、日段、进院等）出现和收起都是一帧硬切：`_notice_time > 0` 时 `visible = true` 且不透明，时间一到整块消失。纸签本身（REQ-025）已经是暖纸墨字，和院里其他反馈（小路蜗牛淡入淡出、拾起名字纸签淡入、照片题注随相片淡入）相比，只有这条底部提示还在硬切，正好落在玩家抬头读字的那一刻。

## 决定

- 新增 `scripts/ui/notice_fade.gd`：`alpha(remaining, age, reduced_motion)`。普通动效：前 0.2 秒从透明淡到全显，剩余时间最后 0.35 秒淡到透明；低动效在整段可读时间内保持全显。
- 新增 `autoload/notice_fade_boot.gd`（与 PaperSliderBoot 同一套路）：在节点进树时绑到带 `_notice` / `_notice_time` 的 Main，本地累加 age，每帧写 `notice.modulate.a`。**不改 `scripts/main.gd`**（开放 #542 等还在动那个文件）。
- 新通知（剩余时间从 0 跳起或换了 key）时 age 归零；钓到鱼只拉长剩余时间、不重启淡入；暂停隐藏时还原 modulate 为 1，避免下次闪一下透明。
- 不改：纸签底色 / 墨色 / 字号 / 贴合宽度 / 位置、通知文案与触发、暂停时立刻隐藏并保留剩余时长、相册 / 确认 / 背篓挡住通知、存档。
