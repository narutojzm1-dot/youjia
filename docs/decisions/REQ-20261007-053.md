## 问题

近郊带上 / 换成一件东西时，`FindReveal` 把物件升到人物头顶，并在上方写出名字（圆石 / 松果 / 落羽，round stone / pine cone / feather）。名字底板是 `draw_rect` 画的**直角方块**，颜色浅黄 `GLOW`、透明度 **85%**：

- 路面和草的纹理会从底板透上来，名字像贴在一块半透明胶带上；
- 同一画面的看景字幕是 14px 圆角暖纸，全局悬停提示（REQ-041）是 8px 圆角、1px 柔棕边的近不透明暖纸——这块直角方块是这条展示线上唯一没有纸感的底板。

几何本身没有越界：Godot 4.7.2 headless 实测 中英 × 7 个视口 × 普通 / 低动效，每帧名字都在屏内，也没有压字幕或底部按钮（新 suite 继续守住这些）。

## 决定

只改 `scripts/exploration/find_reveal.gd` 的名字底板：

- 底板改用 `PaperTooltipStyle.panel()` 同一张暖纸：`PAPER` 97% 近不透明、1px 柔棕边 `9c7f68`、8px 圆角、淡墨投影（本处投影收为 size 3 / 下移 2，免得顶到上方预留空间之外）。
- 纸签尺寸 = 字宽 + 左右 9px，字体上下沿（17px：20 + 5）+ 上下 3px；字按字体上下沿上下居中，水平以物件为中。
- 纸签下沿在物件中心上方 `HALO + 2`（不压展示圆片与其阴影）；纸签连投影的上沿仍在 `near_path_scroll` 为名字预留的 `HALO + 8 + LABEL_ROOM`（96px）以内，所以字幕下方的避让与原来一致，`near_path_scroll.gd` 不用改。
- 淡出：纸面、边、投影和字的透明度都乘以展示光晕，和原来名字随光晕淡出的时机一致（光晕 > 0.5 才画）。
- 新增 `name_font()`、静态 `name_slip_rect()`、`name_slip_style()` 供测试读几何与样式；删掉不再使用的 `GLOW` 常量。

不改：字体（打包 UI 字体）、17px 字号、墨色 `INK`、何时出现、展示圆片与颜色、升起 / 停留 / 飞入篮子的路径与时长、低动效原地淡入淡出、短音、核心拾取 / 存档。

同屏的提篮名字底板（`near_path_scroll.gd` 的 `basket_label_rect`）也是直角浅色块；该文件正被 #521 修改，本片不碰，留作 #521 合入后的独立小片。
