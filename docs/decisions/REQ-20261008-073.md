# REQ-20261008-073 近郊拾起短展示的名字纸签随光晕淡入、飞向篮子时淡尽，不再半透明一下冒出 / 消失

## 问题

在近郊画卷拾起圆石 / 松果 / 落羽时，`FindReveal` 让物件从路边升到人物上方停一下再飞进提篮，名字画在上方一张暖纸小签上（REQ-20261007-053）。名字只在光晕 `halo > 0.5` 时画，透明度直接等于光晕：

- 升起时，光晕越过 0.5 的那一帧，纸签和字以约 50% 不透明整块冒出；
- 飞向篮子时，光晕跌破 0.5 的那一帧，纸签和字又从约 50% 不透明一帧消失。

60fps 下这是一次约 0.5 的透明度跳变，物件、光晕都在平滑运动，只有名字硬切，正好落在「拿到东西」这一刻。

## 决定

- 新增 `FindReveal.name_fade(halo)`：光晕 ≤ 0.5 时为 0，0.5→1 线性升到 1。纸签底色 / 边 / 投影和字都用它，不再直接用光晕。
- 效果：升起时名字从透明淡入，停留时全显，飞走时对称淡尽；60fps 下每帧透明度变化 ≤ 0.25（原来 0.5 的一次跳变）。
- 不改：名字何时被画（仍是光晕 > 0.5）、停留 0.9 秒全显、纸签样式与位置、字号与字体、升起 / 停留 / 飞行时长与路径、短音、`settled` 只发一次、低动效（光晕恒为 1，名字全显，整段由 `modulate` 淡入淡出）。
- `name_slip_style(fade)` 接口不变，只是传入值由光晕换成 `name_fade(光晕)`，原 `find_reveal_name_slip_suite` 的断言照旧成立。
