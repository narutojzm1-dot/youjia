## 问题

近郊画卷（`scripts/exploration/near_path_scroll.gd`）的五个按钮（回院、暂停、停下看看 / 去村边、拿上 / 收养、继续走）都设成 `MOUSE_FILTER_IGNORE`，点按统一由 `press_at()` 命中后直接 `pressed.emit()`。所以 Godot 自带的「按下 / 悬停」底永远不会出现：

- 点中「停下看看」「拿上」时按钮外观一帧都不变，只有后面的场景变化告诉玩家点到了；动作慢一点（例如收养要等保存）时，玩家会以为没点中而再点一次；
- REQ-057 已让不可用和可用一眼分开，但「可用且刚被点中」仍和「没点」一模一样。

## 决定

- 新增 `tap_style()`：按下的杏纸 `f3d3ae` + 墨色 `5b4637` 2px 边，与院内背篓按钮（REQ-056）按下态同一色板；边宽、圆角 16、内容边距与可用底完全相同，按钮不跳大小。墨字在 `f3d3ae` 上对比约 6:1（≥4.5:1）。
- `press_at()` 命中**可用**按钮时先 `flash_tap(button)`：把该按钮的 `normal` 底换成 `tap_style()`，0.14 秒后在 `_process` 里换回原来的奶油底 + 杏边；连点会重新计时，每次点按仍只触发一次动作。
- 不可用按钮被点：不触发（原逻辑）、也不显示按下。点路面：没有按钮显示按下。
- 暂停 / 失焦（原 `_notification` 分支）和 `release()` 离开画卷时立即收回，回来时按钮不会停在按下的样子。
- 只是 0.14 秒的颜色变化，没有位移或缩放，低动效设置下同样适用。
- 不改：按钮文字、尺寸、位置、`button_style()` 各状态（REQ-057 的专项照旧通过）、点按命中判定、键盘快捷键、触屏去重、探索核心与存档。
