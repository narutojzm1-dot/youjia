## 问题

REQ-030 让确认纸片宽 `min(420, 屏宽 − 24)` 居中、四边留 12px。但纸片里两颗按钮（「好 / 再待一会儿」「Yes / Stay」）来自 `_soft_button()`，最小宽固定 260px；纸面左右各 16px 内边距，所以纸片最窄只能是 292px。Godot 4.7.2 headless 实测：

- **280×653（折叠屏外屏等）**：纸片 292px 宽、x = −6，左右各伸出屏外 6px，圆角、描边和两颗按钮两端都被裁掉；中英文都一样。
- **300×560**：纸片 292px，两边只剩 4px（设计 12px）。
- 屏宽 ≥ 316 时 260 + 32 ≤ 屏宽 − 24，原来就没问题。

审计脚本同时扫了标题页、游戏中 HUD、暂停页（中英 × 8 个视口含 280 / 320 宽竖屏与 568×320 / 640×300 矮横屏），只有这一处越界。

## 决定

只改 `scripts/main.gd` 的 `_fit_confirm_panel()`（另加常量 `CONFIRM_BUTTON_WIDTH := 260.0`）：

- 算出纸片内宽 = 纸片宽 − 纸面样式左右内边距；两颗确认按钮最小宽取 `min(260, 内宽)`。
- 只有内宽不足 260（屏宽 < 316）时才收窄：280 宽 → 224px，300 宽 → 244px。按钮仍 44px 高、字号 16 不变，「再待一会儿」「Stay」都放得下。
- 内宽 ≥ 260 的所有屏幕（含 320×568 以上竖屏、矮横屏、1280×720）按钮仍 260px，纸片尺寸、位置、字号、文案与改前完全一致。
- 版面变化（转屏、窗口缩放）时 `_layout()` 已调用 `_fit_confirm_panel()`，打开中旋转也会跟着收放。

不改：文案、字号、颜色、纸面样式、按钮高度、标题页 / 暂停页 / 相册 / 存档的其他 `_soft_button`、确认 / 取消行为、`_soft_button()` 本身。
