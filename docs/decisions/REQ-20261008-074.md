## 问题

在院子里点一下草地，旅人走过去时，落点画一个奶黄色圈（`YardWorld._draw` 里 `draw_arc(_walk_goal, 10.0, …)`）。这个圈是正圆、半径固定 10、没开抗锯齿，点下那一帧整圈 0.85 不透明直接出现。院子里所有贴地的东西——旅人和动物的接触影、摆好的小物底影、点不到时的断弧——都是压扁的椭圆、随 `YardGround.depth_at` 远小近大；只有落点圈是竖着的正圆、远近一样大，看起来像贴在屏幕上的贴纸，不像落在草地上的记号。

## 决定

- 新增 `scripts/game/walk_goal_marker.gd`（纯函数，无 class_name，`YardWorld` 用 preload 引用）：
  - 颜色、0.85 不透明度不变（`1.0,0.92,0.65`）。
  - 形状：横半径 `10 × depth`、竖半径压扁到 0.45 倍，贴地；中景（depth 1）横向仍是原来的 10。远处约 8.2、近处约 11.8。
  - 线条：32 段闭合折线，统一 2px，开抗锯齿（不用非等比缩放画弧，避免上下边变细）。
  - 淡入：点下那一帧从透明开始，0.15 秒线性到 0.85；之后一直全显。
  - 低动效：点下那一帧直接 0.85 全显，大小与普通一致、不变。
- `YardWorld`：新增 `_walk_goal_age`，只在 `try_walk_to` 接受新落点时归零，`tick` 里有落点时累加（不读系统时钟）；`_draw` 用 `WalkGoalMarker.pose` / `points` 画。
- 不改：落点判定、能否走到、寻路、到达 / 清除时机、键盘移动立即清除、点不到时的断弧、动物 / 交互目标跟随、相册与存档。
