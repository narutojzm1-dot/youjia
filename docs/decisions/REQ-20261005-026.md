# REQ-20261005-026 网页高清屏按 CSS 像素排版：手机上字和按钮不再缩小

- Agent-ID: `GROK-CONTRIBUTOR`
- 日期：2026-10-05

## 背景

GAME-QA 14:34 冒烟（`docs/playtests/2026-10-05-1434-game-qa/`）的 Windows Chrome 截图里，左上目标提示、顶部“假期第 4 天”比设计小很多：截图就是 1260×886 的 CSS 视口，提示纸片在里面约 308px 宽，而 `_layout()` 设计是 520+18=538px，比值约 1.75，正好是该机器的缩放倍率。原因不在字号本身：

- Godot Web 导出默认开着 hidpi，画布按 `CSS 尺寸 × devicePixelRatio` 建（`game.js` 里 `GodotDisplayScreen.hidpi:true`）。
- 本项目 `window/stretch/mode="disabled"`，`Main._layout()` 直接用物理像素的 `size` 排版。

于是在任何 DPR > 1 的设备上，15px 目标提示、14px 天数、16px 通知、48px 按钮都只剩 1/DPR 大；Windows 150% 缩放时缩到 2/3，DPR 3 手机缩到 1/3。更严重的是竖屏手机：390×844 CSS、DPR 3 时物理宽 1170 ≥ 700，`compact` 判成桌面，按钮横排在右下，手机竖屏布局（全宽行动按钮、天数下移）根本不会出现。已有 390×844 / 844×390 Web 验收都在 DPR 1 的 Chromium 里跑，所以一直没暴露。

## 决定

新增 `scripts/ui/web_hidpi.gd`（`WebHiDpi`，规则）和自动加载 `autoload/web_hidpi_boot.gd`（`WebHiDpiBoot`，在 `project.godot` 的 `[autoload]` 里排在 `TuningStore` 之后）。自动加载节点先于主场景就绪，在 `Main` 首次布局前定好倍率；根窗口尺寸变化时延迟再定一次。`scripts/main.gd` 一行不改：

- 只在 Web 读 `DisplayServer.screen_get_scale()`（即浏览器 devicePixelRatio）；原生桌面恒为 1，不改。
- 把根窗口 `content_scale_factor` 设为这个倍率（< 1、NaN、无穷按 1，上限 4）。stretch 仍是 disabled：Godot 在这种模式下把逻辑尺寸变成 `物理尺寸 / 倍率`，画面仍按物理分辨率渲染，字体按倍率超采样，所以不会变糊。
- 结果：`Main.size` 回到 CSS 像素，`_layout()` 的 compact 判断、字号、按钮尺寸和镜头取景都与同一 CSS 尺寸、DPR 1 时一致；输入坐标由引擎按同一变换换算，`_screen_to_world` 不用改。
- 浏览器缩放或把窗口拖到另一块屏会改 DPR，并伴随一次画布尺寸变化，此时重新读倍率。

## 不做

- `project.godot` 只加一行自动加载，不改 stretch 设置；不改导出预设或 `web/loading.html`（加载页归 #167）。不改 `scripts/main.gd`。
- 不改任何字号、配色、HUD 文案或布局阈值；不改 `YardWorld`、相册、存档、钓鱼或资源。
- 不改 `tools/verify_daily_life.sh`（本通道的文本 API 会把它的可执行位改成 100644，见 #276）；新 suite 请合入方追加到 daily 列表末尾，本地已按追加后的列表完整跑过。

## 验收

1. `test/web_hidpi_suite.gd` 102 项全过，退出码 0：自动加载已注册；倍率规则；1170×2532@3、1688×780@2、1920×1080@1.5、1280×720@1 四种画布下 `Main.size` 回到 CSS 尺寸，提示/天数/三颗按钮/暂停/通知位置、尺寸、字号和镜头缩放与同 CSS 尺寸 DPR 1 一致，按钮都在屏内；DPR 2.625 的 412 宽竖屏走 compact；DPR 从 3 变 2 后重新读倍率仍是 390×844 竖屏布局。
2. 同一 suite 去掉 `project.godot` 那行自动加载后 39 项失败（例如 1170×2532@3 的行动按钮在 (962, 2464)、宽 188，而 390×844 设计是 (20, 776)、宽 350）。
3. 真实高清屏浏览器（DPR 2/3 手机或 Windows 150%）需要合入方或 QA 在导出包上复核，本通道只有无界面 Godot。
