# REQ-20261005-029 目标纸片按实际行数伸缩

## 背景

左上角的目标提示（`_hint_label`）下面垫着一张纸片（`_hint_panel`）。`_layout()` 里两者高度写死：窄屏文字区 64、纸片 80；宽屏文字区 48、纸片 64。实际文字行数并不固定：

- 844×390、700×400、1280×720：中文全部、英文绝大多数只有 1 行（约 23px），纸片却有 64px，下半截是空纸，压住远山和天空。
- 390×844 英文：最多 4 行（例如走到水塘岸石边：`Target: Pond-side stones / Touch the water · Space/ button`）。文字需要 101px，文字框只有 75px、纸片 80px，最后一行 `button` 落在纸片下沿外面，直接压在树叶上。
- 360×640：中文最多 3 行、英文最多 4 行，同样溢出纸片。

## 决定

只改 `scripts/main.gd`：

- 新常量 `HINT_MIN_TEXT_HEIGHT = 32`：文字区最小 32px，纸片最少 48px，和「歇一会儿」按钮同高。
- 新函数 `_fit_hint_panel()`：文字区高度 = 实际行数 × 行高 + (行数 − 1) × 行距，至少 32；纸片 = 文字区 + (18, 16)，和原来的外边距一样。
- `_build_hud()`：目标文字改为垂直居中。
- `_layout()`：宽度和位置的算法不变，只把写死的 64/48 换成先设最小高度，再调用 `_fit_hint_panel()`。
- `_refresh_hud()`：每次换文字后调用 `_fit_hint_panel()`。这样走动换目标、切换语言、横竖屏切换都会重新贴合。

实测：844×390 单行纸片 64 → 48；390×844 中文两行 80 → 65；390×844 英文四行 80 → 117（文字全部在纸上）；360×640 中文三行 → 91。纸片宽度不变，不碰「歇一会儿」按钮和天数纸签。

## 不做

- 不改提示文案、字号、颜色、宽度、位置、纸片样式、点击穿透。
- 不改暂停页、通知（#348）、手帐（#350/#351）、标题页、存档、探索。
- 不改 `tools/verify_daily_life.sh`（本通道的文本 API 会把可执行位改成 100644，见 #276；#351 也在改这个文件）。新 suite 请合入方追加到 daily 列表末尾。
- 不改 `docs/requirements.md`（多个开放 PR 在追加），登记行见下。
