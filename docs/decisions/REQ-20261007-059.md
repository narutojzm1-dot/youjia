## 问题

REQ-043 只处理了矮横屏；竖屏和大屏（高 ≥ 500）的暂停纸片仍固定为 `min(620, 屏高 − 24)`：

- 390×844：纸片 620px 高（y 112–732），单列内容连纸边距只有约 553px，标题上方和最后一个按钮下方各空出约 43px 纸；
- 纸片下端压住底栏「翻开手帐 / 大太阳 / 大背篓」一排按钮（y 720 起）的上沿约 12px，暂停时底栏看起来被切掉一截；
- 1280×720：纸片 620px（y 50–670），盖住底栏按钮（y 652 起）约 18px。

## 决定

高屏也按内容贴合：纸片高 = `min(620, 屏高 − 24, 内容 + 纸面上下内边距 + 2 × PAUSE_TALL_BREATH)`，`PAUSE_TALL_BREATH = 20`（矮屏仍是 14）。

- 宽度 360、单列、居中、字号 26/16、按钮最小高 44、滑块高 32、中英文案、所有按钮行为都不变。
- `_on_pause_content_resized` 不再只在矮屏生效：语言切换、内容最小高变化后高屏同样重新贴合，宽度按矮/高屏各自规则传入。
- 结果：390×844 纸片 620 → 593px（y 125.5–718.5），底栏按钮与右上「假期第 N 天」小签都完整露出；412×915 同样不压底栏；1280×720 620 → 593px，与底栏重叠从约 18px 降到约 4.5px（内容本身约 553px，这一档不再强求完全不重叠）。
