## 问题

院内布置面板（`scripts/ui/yard_decor_panel.gd`）的纸面总是占满它的整段额度：

- 横屏额度是「屏高 − 16」。五行按钮（位置 / 小物 / 方向 / 确认收回）加说明只需约 280px（英文约 307px），但 1280×720 上纸面高 704px、1920×1080 上 1064px：按钮挤在顶部，「回到背篓」被推到最底，中间是约 420 / 780px 的空白暖纸，像一条贴着右边的整屏纸带。844×390 上也空出约 94px。
- 竖屏额度是 `min(320, 屏高 × 48%)`。390×844 上按钮只要 280px，纸面仍占 320px，上方预览区少了 40px。

## 决定

纸面高度改为 `min(原额度, 内容所需高度)`：

- 内容所需 = 纸面上下内边距 + 说明文字按实际纸宽换行后的高度 + 按钮列最小高度 + 「回到背篓」+ 两处行距；说明换行在测量前先按真实宽度排好。
- 横屏仍贴右上角（右 8px、上 8px），宽度不变；竖屏仍贴左下角（左 8px、下 8px），宽度不变。
- 内容放不下额度时（如 320×568、568×320、英文 640×300），高度停在原额度、照旧滚动，与改前一致。
- 「再确认保存」出现 / 消失、切换语言、说明文字变长时，原有的延迟 `fit()` 会重新贴合。
- 不改：按钮样式（#533）、44px 触控、文案、预览逻辑、触摸点按 / 滑动路线、存档与布置流程。`preview_rect()` 公式不变：横屏预览区本来就在纸面左侧；竖屏纸面变矮后预览区只会更大，不会变小。
