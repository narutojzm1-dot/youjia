## 问题

院里的大背篓（`scripts/ui/yard_basket_panel.gd`）自己建按钮，不走 `Main._soft_button`。它的悬停、按下、禁用三态共用同一块 `#eadcc8` 底和同一条 1px `#b88a61` 边，禁用时只把字调浅到 `#7a6152`，字对底约 **4.25:1**（低于 4.5:1）。

于是背篓空着、手里已经拿着东西、或者正在确认保存时，一整列「拿一条 / 拿一束 / 收回背篓」看起来像是全被按住了，和鼠标悬停在可点按钮上一模一样，字反而比可点的更难读。REQ-038 只修了 Main 的暖纸按钮，背篓这一套没跟上。

## 决定

只改背篓按钮的**禁用态**，直接用 REQ-038 已在 main 上的同一组值：

- 底 `#f3e9db`（淡一档的暖纸），边 1px `#bfa588`（浅棕），字 `#7a6152`，字对底约 **4.78:1**，仍比可点时的墨字（约 8.5:1）浅。
- 可点 `#fffaf1`、悬停 / 按下 `#eadcc8`、边 `#b88a61`、焦点 2px `#916d49` 描边、圆角 12、最小尺寸 104×44、17px 字号：**全部不变**。
- 文案、何时禁用（空档、忙、手里有东西、数量为 0）、触屏点按逻辑：不变。

把原来散写的颜色收成 `BUTTON_*` 5 个常量，只是为了让禁用态和 Main 的值对得上、测试能锁住。
