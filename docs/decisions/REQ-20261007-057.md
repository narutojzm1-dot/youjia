## 问题

近郊画卷里的五个按钮（回院、暂停、看看/去村边、拿上/收养、继续走）都由 `scripts/exploration/near_path_scroll.gd` 的 `_button()` 生成，normal / hover / pressed / disabled 共用同一块奶油底 `fffaf1` + 杏色 2px 边，且只覆盖了 `font_color`：

- 「收养」「收养乌龟」在保存未落盘或收养进行中会被设为 disabled（`_refresh()`），点它没有反应，但按钮外观和可用时一模一样；
- disabled 时字色回落到 Godot 默认主题的 `font_disabled_color`（约 `dfdfdf` 半透明浅灰），画在奶油底上几乎看不见，玩家看到的是一个「空白按钮」；
- `hover_pressed` 没有覆盖样式，会掉回默认灰底；hover / pressed 字色也回落为默认近白色。目前这些按钮 `mouse_filter = IGNORE`，由画卷自己的点按逻辑触发，所以平时画不到这些状态，但一旦以后放开鼠标事件就会出现白字灰底。

## 决定

只改 `_button()` 的样式，不动排版、文案、点按逻辑：

| 状态 | 底色 | 边 | 字 |
| --- | --- | --- | --- |
| 普通 / 悬停 / 按下 / 按住时悬停 | `fffaf1`（不变） | `f3b27a` 2px（不变） | `5b4637` 墨色 |
| 不可用 | `f3e9db` 浅纸（与 #531 布置面板、#541 背篓面板同值） | `bfa588` 褪色 2px | `8a7060`（画卷已有 `MUTED`，对浅纸约 3.8:1） |

- 新增常量 `DISABLED_FILL` / `DISABLED_EDGE` 与静态 `button_style(state)`；各状态边宽、圆角、内容边距相同，切换可用性时按钮最小尺寸不变。
- 不可用按钮仍按原逻辑吞掉点按、不触发动作。
