## 问题

拍立得快照里已经记下了当时的天气（`PhotoMoment.capture` → `weather`: sun / overcast / rain），手帐说明却只写「假期第 N 天」+ 瞬间文案。翻到阴天或细雨那天拍的照片时，文字上看不出天气，和 HUD 上已有的「大太阳 / 阴天 / 细雨」纸签语言不一致。

## 决定

- `PhotoDiary.caption`：快照带合法 `weather` 时，在瞬间文案前垫 `hud.weather.*` 标签 + ` · `（复用既有 i18n，不改 localization JSON）。
- 无 `weather`、未知值、或旧存档没有 `day`：行为与改前完全一致（不发明天气、不发明第 1 天）。
- 新增 `PhotoDiary.weather_crumb` 供套件与展示复用。
- 不改：`PhotoMoment` 捕获 / sanitize、相册布局、`photo_arrival`、Main、存档格式。
