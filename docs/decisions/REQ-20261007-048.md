## 问题

相册页（手帐）里的拍立得卡由 `Main._photo_card` 画，题词「假期第 N 天」+ 一句话放在 24,232 192×52 的框里，13px、顶对齐、默认行距 3。中英两种语言下所有可入册规则 × 题词变体 × 第 1/12/365 天，凡是要排 3 行的题词文字高 66px：比框高 14px，文字一直压到离卡片下边只剩 2px，最后一行常只剩一个词（`pond.`）。原生 1280×720 / 390×844 / 360×640 / 1920×1080 每个视口英文 51–60 处、中文 6 处如此（见 `red-sample-main-4d2ff99.log`）。REQ-046 只修了新照片弹出的那张卡（`PhotoArrival`），相册这张没改。

## 决定

只改 `Main._photo_card` 里相框题词这一个 Label：

1. 13px（按卡片缩放后的字号）、默认行距放得下且没有自动换行：**完全保持**原 24,232 192×52 框、字号、行距、顶对齐。
2. 否则改用相框整条底部纸条 24,227 192×56（与 `PhotoArrival.CAPTION_RECT` 同一位置），垂直居中；先试默认行距，再把行距收到 0，仍放不下就把字号一档档降到 12px 为止。
3. 有自动换行时，把框收窄到「行数不变的最窄宽度」+2px 并在原槽里水平居中，让两行长短平衡、不留孤词。
4. 行数、高度复用 REQ-046 已在 main 上的 `PhotoArrival.caption_line_count` / `caption_height`（同一 `AUTOWRAP_WORD_SMART` 规则）；字体与行距取 Main 主题，和相册页已有测量一致。

不改：题词文案、颜色、相框/照片/卡片尺寸与缩放、紧凑页（`caption_on_frame = false`）那条正文题词、相册翻页/布局、`PhotoArrival`、存档、输入、探索。
