# REQ-20261005-027 假期天数挂到「歇一会儿」下方的小纸签（#338）

- Agent-ID: `GROK-CONTRIBUTOR`
- 日期：2026-10-05
- 来源：#338（CODEX-LEAD 拆出，Owner 建议 GROK-CONTRIBUTOR，本人回执 #338 评论 5991662232）

## 背景

HiDPI（REQ-026，PR321）合入后，真机手机就是 390×844 / 844×390 的 CSS 视口。在 main `9fd261d` 上用原生 Godot 4.7.2 重新渲染：

- 竖屏 390×844：天数在 (20, 100)，160×28，`MUTED` 色、无底，浮在目标纸片下方的树叶上，几乎看不清。
- 横屏 844×390：不是 compact，天数居中到 (342, 20)，正好落进目标纸片 (11, 9, 538×64) 里，和目标文字挤在同一条。
- 1280×720：居中 (560, 20)，没重叠，但同样无底。

## 决定

只改 `scripts/main.gd` 的两处：

- `_build_hud()` 里 `_day_label`：字色改 `INK`，加一张和目标纸片同色系的小纸底（`PAPER` 0.90、`APRICOT` 0.65 细边、圆角 10，上下边距 2、左右 8），文字上下居中。字号 14 不变，仍忽略点击。
- `_layout()` 里天数那一支：宽度等于暂停按钮宽，挂在暂停按钮正下方 8px（`y = 暂停.y + 暂停.高 + 8`），横竖屏一致。结果：390×844 在 (250, 76) 120×28，844×390 在 (636, 76) 188×28，1280×720 在 (1072, 76) 188×28，都在目标纸片右侧之外。

## 不做

- 不改 `_on_album_updated`、存档、启动流程；不改 #322 的探索方法；不改文案、字号、其他按钮或通知位置。
- 不改 `tools/verify_daily_life.sh`（本通道的文本 API 会把可执行位改成 100644，见 #276）；新 suite 请合入方追加到 daily 列表末尾；本地完整跑了现有 daily，并单独跑了新 suite。
- 不改 `docs/requirements.md`（多个开放 PR 在追加），登记行见下。
