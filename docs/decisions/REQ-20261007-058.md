## 问题

院里大背篓（`scripts/ui/yard_basket_panel.gd`）和院内布置面板（`scripts/ui/yard_decor_panel.gd`）的清单都放在 `ScrollContainer` 里，竖向滚动条一直沿用 Godot 默认主题：

- 槽是 `1a1a1a` @ 0.6 的深灰块，叠在 `fff6e8` 暖纸上合成约 `76756c` 的一条灰带，是两张纸上唯一一条深色、不属于纸面配色的东西（同 REQ-040 修过的默认音量滑块一类问题）；
- 滑块是半透明白色 `ffffff` @ 0.4，悬停 @ 0.75、拖动浅灰，都只是「灰上加白」，与按钮、滑块、提示纸的暖色体系无关；
- 这条条子实际经常出现：自测中大背篓在 280×653、320×568、390×844、568×320、844×390、1280×720 都有溢出（矮横屏 568×320 只露出约 191/443px 清单），布置面板在竖屏和 568×320 也会出现。

## 决定

新增 `scripts/ui/paper_scrollbar_style.gd`（与 `PaperSliderStyle` / `PaperTooltipStyle` 同类的纯样式文件），两个面板创建 `ScrollContainer` 后各调用一次 `PaperScrollbarStyle.apply(scroll.get_v_scroll_bar())`：

| 部位 | 颜色 | 说明 |
| --- | --- | --- |
| 槽 `scroll` / 聚焦槽 `scroll_focus` | `eadcc8` | 与暂停页音量滑块的浅槽同值；对纸面约 1.26:1，只是一道浅沟，不再是深灰带 |
| 滑块 `grabber` | `8a7060` | 已用于不可用字色的 MUTED（#545）；对槽约 3.4:1、对纸面约 4.3:1 |
| 悬停 `grabber_highlight` | `7d6250` | 深一档 |
| 拖动 `grabber_pressed` | `5b4637` | 面板墨色 |

- 所有状态圆角 4、四边内容边距 4，最小宽度仍是 8px（与默认主题相同），因此清单宽度、每行名字折行、按钮位置、触摸拖动滚动、点按判定全部不变。
- 只作用于这两个面板自己的滚动条，不改共享主题，不影响开源许可等其它对话框。
