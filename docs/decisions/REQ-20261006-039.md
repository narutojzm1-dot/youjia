## 背景

- 竖屏手机（390×844、360×640）：这行字正好落在屋顶深色木梁和窗台花上，墨字对身后屋顶取样约 2.5:1，中英文都要眯眼看；
- 短横屏（568×320、640×300、844×390）：这行字横穿左上角目标纸片的「目标：窗台花箱 / Target: Window flowers」，两行字叠在一起，两边都读不出；
- 1280×720：落在雪山上，勉强能读。

## 决定

只改 `scripts/ui/photo_arrival.gd`：

- 在 `ShutterCaption` 下加一个子节点 `ShutterPaper`（`Panel`，`show_behind_parent`，不接收鼠标），画在字后面。
- 纸片：PAPER `#fff6e8` α 0.94、1px APRICOT `#f3b27a` α 0.6 细边、圆角 12，与通知/标题纸片同一家族。
- 宽 = 实际文字宽 + 左右各 14px（不超过原 360/屏宽−24 的行框），高 = 一行字高 + 上下各 3px，居中；字改为垂直居中，行框位置/尺寸仍完全由 `fit_layout()` 决定。
- 切语言（`refresh_locale`）、旋转/改窗口（`_layout`）时重新贴合。
- 纸片是这行字的子节点，自动跟着它一起淡出；低动效静帧时一直显示，与原行为一致。
- 墨字 `#5b4637` 不变；纸片压在任意底色上（黑、白、深木、浅木）对比 7.2–8.3:1。

## 不做

- 不改相纸、照片、题词、时间、缩放、淡入淡出时长、低动效逻辑；不改 `fit_layout()`。
- 不碰 `scripts/main.gd`（#455 与 Assistant #382 在改）、目标纸片、通知、相册、存档、输入或探索。
- 不改 `tools/verify_daily_life.sh`、`tools/lib/godot_suite_completions.tsv`、`docs/requirements.md`；新 suite 和需求行交合入方登记（见下）。
- 不冒真实浏览器/DPR/手机验收；只做原生取值、布局与原生渲染。
