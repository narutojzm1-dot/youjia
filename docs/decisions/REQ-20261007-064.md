## 问题

#565 图8：大背篓现在是一列「名字 × 数量 + 拿一条」的清单，松果 / 圆石只有数量没有操作。用户要标准行列格子，所有物品可操作，点击物品弹操作、手机可用；拖出时面板半透明、合法摆放区着色。明确「不能只给旧列表补按钮」。

## 本切片决定（只做格子与点按操作）

- 新组件 `scripts/ui/yard_basket_grid.gd`，接口与 `yard_basket_panel.gd` 一致：`update_view(inventory, keepsakes, state, busy)`、`action_requested(action, kind)`，另有 `press_at(position)` 供触屏统一点按。
- 八样东西各一格，固定顺序：小鱼、中鱼、奇怪的鱼、草束、小米、圆石、松果、落羽。每格：上方数量角标「×N」、中间原画（鱼 `objects/ground_fish.png`，小鱼 / 中鱼按格内占比缩小，不改色；草束 `fx/grass_bundle.png`；小米 `objects/millet.png`；三种小物沿用 `KeepsakeArt.texture()`）、下方名字。英文格内用短名（Small / Odd fish / Stone / Cone），完整名在纸片标题和悬停提示里；名字放不下最多从 14 收到 12px，不折行。
- 列数按纸内宽度：放得下 4×64px 加间距就 4 列，否则 3 列（280 宽手机纸内约 224px）。最后一行用浅纸空格补齐，看得出是一张格子。每格至少 64×88，大于 44px 触控下限；三层（角标 / 原画 / 名字）互不重叠。
- 数量 0 的格子：原画淡到 32%，名字与角标用背篓 0 行同一 `7a6152`（REQ-061），不可点。手里拿着的那样即使背篓里 ×0 仍可点（为了收回）。
- 点有货的格子：格子保持背篓按下态（`f3d3ae` 杏纸 + 2px 墨边，与 REQ-056 同色板），旁边弹出一张小纸片（优先在格子下方，放不下翻到上方，左右夹在屏内），标题「名字 ×N」、一个动作、一个「算了」：
  - 鱼：拿一条 → `withdraw`；草束：拿一束 → `withdraw`；小米：拿一把 → `withdraw`。
  - 圆石 / 松果 / 落羽：摆到院里 → `decor`（新动作 id，接线时由 Main 打开院内布置并预选该小物）。
  - 手里正拿着的那样：收回背篓 → `return`。
  - 不能做时动作灰掉并写原因：正在确认保存 / 背篓未载入；手里已拿着别的食物时「先把手里的草束收回背篓」；小物在手里拿着食物时仍可摆。
- 关闭：点「算了」、再点同一格、点纸片外、Esc；点到别的格子直接换过去。关闭路径都不发动作。点纸片上灰掉的按钮或纸片空白处不会漏到下面的格子。
- 动作按钮获得焦点时保持墨色字，只加一圈 `916d49` 褐边（与背篓按钮相同），不出现引擎白字灰底。

## 第二切片：接入背篓面板与 Main（2026-10-08，回应 CODEX-LEAD [PR 评论](https://github.com/narutojzm1-dot/youjia/pull/570#issuecomment-6041685883)）

- `yard_basket_panel.gd`：清单滚动区顶部放入格子（`grid`），`update_view` 同步喂给格子；旧的三行小物、五行「名字 × N + 拿一条」节点仍建出、信号照旧（`fish_buttons` / `fish_labels` / `keepsake_labels`），但隐藏（`list_rows`），同一样东西不再出现两遍。手里拿着、舀米、收回背篓、「把小物摆在院里」、保存提示、重试、合上照旧显示在格子下方。
- 格子的 `withdraw` / `return` 照旧经 `action_requested` 交给 Main 的 `_inventory.request`；新 `decor` 动作不进库存事务，由面板 `open_decor_with(kind)` 处理（见下）。

- 防止无限重排：格子按背篓纸内宽减去滚动条宽排列（`set_layout_width`），不随滚动条显隐来回变宽——否则「格子变高 → 出滚动条 → 变窄 → 格子变矮 → 滚动条消失」会把消息队列撑爆（本地专项实测崩溃后修复）。名字字号没变时不重设主题覆盖。
- 「摆到院里」不改 `scripts/main.gd`：面板触发现有「把小物摆在院里」按钮（Main 已接到 `_show_decor()`，收起背篓、打开布置面板、保存相机），再在布置面板上预选：当前选中位置已有摆件就换到 `yard_decor.gd` `SPOTS` 中第一个空位，然后 `choose_find(find_id)` 进入现有预览。不提交、不扣可用数量，确认仍走布置面板 `commit`（Leader 的 `YardDecorController.request('place', …)`）。布置面板引用 `decor_panel` 可由 Main 直接赋值；未赋值时在同一 UI 层按脚本路径找一次——集成时如愿意，Main 加一行 `_basket_panel.decor_panel = _decor_panel` 即可替掉查找。之所以不改 Main：它 12 万字节、几个在途 PR 都在动，作者只能整文件推送，风险大于收益。
- Esc 照旧由 Main 直接合上背篓，打开着的纸片随背篓一起收起（面板隐藏时收纸片）；点纸片外任意处只收纸片、不触发下面的按钮。
