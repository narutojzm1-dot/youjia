# REQ-20261006-037 新照片相纸：照片四周不再透出后面的院子

- Agent-ID: `GROK-CONTRIBUTOR`
- Owner: `GROK-CONTRIBUTOR`
- 日期：2026-10-06
- 来源：每小时自选无主 UI 切片（用户 2026-10-05：界面切片主要归 Grok）。在 main `8f464b2` 上用原生 Godot 4.7.2 把新照片相纸（`PhotoArrival`）叠在真实院子画面上渲染发现：照片四周有一圈约 12–16px 的「窗」，透出后面的房子、底部提示文字和按钮，看起来像照片被抠了洞。无其他 Owner 认领；不碰 #444 的 `Main._soft_button`、#400 的院景相机偏移、#375 的拾起展示。

## 背景

`polaroid_frame.png`（360×448）中间是透明窗，纹理坐标约 x 24–337、y 23–341。相纸卡 240×300 按 `STRETCH_KEEP_ASPECT_CENTERED` 画这张纹理，窗落在卡内约 (16,16)–(225,228)，约 210×212。照片 `PhotoMoment` 只有 184×184、放在 (28,28)。中间差的那一圈没有任何东西画，于是直接看到相纸后面正在运行的院子。

相册里同一张相框放在纸色书页上，那一圈露出的是书页颜色，看起来像相纸留白，所以没人注意到；新照片却直接叠在院子上，窄屏和短横屏时这一圈正好压着底部提示和按钮，最明显。

## 决定

只改 `scripts/ui/photo_arrival.gd`：

- 在卡里、相框下面加一块不透明暖纸色衬底 `PhotoMat`（`#f3e3cb`，取自相框纸边的颜色），盖住整扇透明窗。
- 衬底范围按纹理坐标 `FRAME_WINDOW_TEXELS = (20,20,322,325)` 换算到卡内（新增 `mat_rect_in_card()`，与 `_frame` 同一套保持比例居中规则），比透明窗每边大 3–4 个纹理像素，边缘全部藏在相框不透明纸边下，不会从外缘露出。
- 衬底是卡的子节点，跟着短横屏缩放、淡入淡出、低动效与收起一起走；不拦点击。
- 照片位置/尺寸、题词位置/字号、卡片尺寸、`fit_layout()`、快门说明、计时、存档、相册都不变。

## 不做

- 不改相册 `Main._photo_card()`（main.gd 正被 #444 修改；相册那一圈露出的是书页底色，不是透出院子）。
- 不放大照片去填满窗：那会改变 `PhotoMoment` 的取景构图和已存照片的观感。
- 不改英文三行题词的排版（实测在卡内、不压照片）。
- 不改 `tools/verify_daily_life.sh`、`docs/requirements.md`；新 suite 请合入方追加到 daily 列表，需求行见下。
- 不冒真实浏览器/手机验收；只做原生几何、纹理透明度核对与原生渲染。
