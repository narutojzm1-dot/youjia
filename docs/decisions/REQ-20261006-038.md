# REQ-20261006-038 暖纸按钮禁用态：不再是没字的灰砖

- Agent-ID: `GROK-CONTRIBUTOR`
- Owner: `GROK-CONTRIBUTOR`
- 日期：2026-10-06
- 来源：每小时自选无主 UI 切片（用户 2026-10-05：界面切片主要归 Grok）。GAME-PM 05:20 公开页空相册截图（`docs/playtests/2026-10-06-0520-game-pm/01-album.png`）里，「← 往前翻」「往后翻 →」是两块灰褐实心块，字几乎看不见。main `67c87f0` 上原生 Godot 4.7.2 复现，存档确认中的「再确认一次」也是同样的灰块。无其他 Owner 认领；#444/REQ-036 只做了焦点/按下态，明确没碰禁用态。

## 背景

标题、暂停、离开确认、相册、存档重试、备份恢复页都用 `Main._soft_button()`。它设了普通/悬停/按下/焦点，但没设 `disabled` 底板和 `font_disabled_color`，于是按钮一被禁用就落回 Godot 默认主题：`#1a1a1a` 30% 透明底板（叠在相册书框 `#e8d5bb` 上实测 `#aa9d8b`）+ 50% 透明近白字，约 1.4:1。

会出现禁用态的地方：

- 相册还没有照片、或在第一/最后一页时的「往前翻」「往后翻」（新玩家第一次打开手帐必见）；
- 存档正在写入/确认/处理时的「再确认一次」；
- 备份恢复页点了「下载两份备份」「继续当前进度」后的处理中。

## 决定

只改 `scripts/main.gd` 的 `_soft_button()`，新增三个常量：

- 禁用底 `SOFT_DISABLED_FILL = #f3e9db`（比可点时的 CREAM 淡一档的暖纸色），1px `SOFT_DISABLED_EDGE = #bfa588` 浅棕边（可点时是 2px 杏色边）；
- 禁用字 `SOFT_DISABLED_TEXT = #7a6152`，对禁用底 4.78:1，读得出，但比可点时的 INK（8.50:1）浅，一眼能分出「暂时不能点」。
- 圆角、内容边距、尺寸、字号、文案、`focus_mode`、行为全不变；禁用按钮照样不响应点击。
- `_chip_button()`（HUD 的「翻开手帐」等）复用 `_soft_button()`，自动带上同样的禁用态；它们目前不会被禁用。

## 不做

- 不改何时禁用（相册翻页规则、存档状态机、恢复页流程都不动）。
- 不碰 #447 的 `photo_arrival.gd`、#382 的 `_input`/modal/slider、REQ-035 的 `_text_button`、REQ-036 的焦点/按下态取值。
- 不改 `tools/verify_daily_life.sh`、`tools/lib/godot_suite_completions.tsv`、`docs/requirements.md`；新 suite 和需求行交合入方登记（见下）。
- 不冒真实浏览器/DPR/手机验收；只做原生主题取值、行为与原生渲染。
