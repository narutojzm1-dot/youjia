## 问题

从背篓格子按住圆石 / 松果 / 落羽拖出来时（REQ-20261007-064 第三切片），背篓纸面变半透明、暗底撤掉，院里还空着的固定位置亮起杏色圈，圈上方写位置名（屋前 / 篱边 / 塘边小路）。这行名字是直接用墨色 16px 字画在院子画面上的，没有底：压在草地、篱笆和塘边深色处很难认，正好是玩家要决定「松在哪」的那一刻。另外，镜头外的那处被贴到屏顶时，名字会画到屏幕外面去。

## 决定

- 每个亮圈的位置名下垫一块小纸签：与背篓纸同色 `fff6e8`（92% 不透明）、`d6ae78` 1px 边、8px 圆角，字仍是背篓墨色 `5b4637` 16px，左右 8px、上下 3px 内边距。
- 手指 / 鼠标正压着的那处（亮着的圈），纸签换成与圈同一条墨边 `5b4637` 2px，和圈一起表明「松在这里」。
- 纸签默认居中放在圈上方 6px；上方放不下（那处被贴在屏顶）就放到圈下方，不盖住圈；最后整块夹在屏内（左右各留 4px）。
- 不改：亮圈的位置、大小、颜色与命中范围，拖动 / 松手 / 取消的逻辑，预览与提交（仍只在布置面板确认），格子、操作纸片、`yard_basket_grid.gd`、`yard_decor_panel.gd`、`main.gd`，存档与库存。
- 位置名文字抽成 `zone_label_text()`，纸签框与样式抽成 `zone_label_rect()` / `zone_label_style()`，供测试直接量。
