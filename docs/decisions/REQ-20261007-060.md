## 问题

院内布置面板（`scripts/ui/yard_decor_panel.gd`）的「← → ↑ ↓」微调箭头，只要有预览就四个全亮。但模型只允许每个方向偏移一格（`dx`、`dy` 都夹在 −1…1，`scripts/inventory/yard_decor.gd`）：

- 按一次 → 之后预览已经在最右，再按 → 什么都不发生，按钮却仍是可点的亮色，玩家以为没点中或卡住了；
- 打开一件已经摆在角上的物件（例如 `dx=1, dy=-1`）时，→ 和 ↑ 一开始就是「按了没用」；
- 触屏上每次无效点按也照样走一遍刷新，没有任何「到头了」的提示。

## 决定

- 新增 `can_nudge(direction)`：忙碌或无预览时为否；否则只有当这一步真的会改变 `dx` / `dy`（未到 ±1 边界）时为是。
- `refresh()` 里每个箭头的 `disabled` 改为 `not can_nudge(该方向)`；走到头的箭头直接用面板已有的不可用样式（REQ-054 的 `f3e9db` 底 + `bfa588` 边 + `7a6152` 字）。另一侧箭头保持可用，往回挪一步后，变灰的那个立即恢复。
- `nudge()` 的早退条件改用同一个 `can_nudge`，与按钮状态一致。
- 方向顺序抽成常量 `NUDGE_DIRECTIONS`，创建按钮和刷新状态共用，避免两处顺序不一致。
- 不改：偏移范围、确认 / 收回 / 取消逻辑、按钮尺寸（仍 ≥44px）、面板排版、触屏点按判定、存档协议。
