## 问题

手机横屏等矮屏（高 < 500）上按「歇一会儿」，暂停纸片固定撑到「屏高 − 24」。844×390 上纸片 366px 高，标题和两列按钮/音量只占中间约 220px，标题上方空 71px、最后一个控件下方空 72px，看起来像一张没排完的大白卡，标题被挤到纸片中部偏上，整体重心发散（原生 4.7.2 + Xvfb 截图与测量见[体验记录](../playtests/2026-10-06-REQ-043-pause-panel-fit/README.md)）。

## 决定

只在矮屏分支收紧纸片高度：

- 高度 = min(屏高 − 24, 内容最小高度 + 纸面上下内边距 + 上下各 14px 留白)，仍居中。
- 内容最小高度用 `_pause_box.get_combined_minimum_size()`。因为单列↔两列重排和切语言后子节点最小尺寸是延迟更新的，另接 `_pause_box.minimum_size_changed`，内容高度真正变化时再贴合一次（不接会在「大屏→矮屏」旋转后多出 12px）。
- 宽度（矮屏 680 / 竖屏 360，均不超屏宽 − 24）、字号（18/13/12）、按钮 36px 最小高、两列分组、竖屏与大屏的 min(620, 屏高 − 24) 都不变。

## 改动范围（方法边界）

`scripts/main.gd` 只动：`_build_pause_screen` 末尾 +1 行连接信号；`_fit_pause_panel` 把写尺寸挪到排版之后；新增 `PAUSE_SHORT_BREATH`、`_on_pause_content_resized`、`_apply_pause_panel_size`、`_pause_content_height`。

不碰：#470 在改的 `_input` / `_toggle_pause` / `_show_title` / 音量回调；#487 在改的存档纸片、`_layout`、`_refresh_hud`、`_refresh_texts`；暂停页文案、按钮行为、滑条样式、确认层、存档、探索。daily 登记各加独立一行（`tools/verify_daily_life.sh` 放在 `still_boundary_feedback` 之后，`tools/lib/godot_suite_completions.tsv` 放在 `pause_notice` 之后），与 #470/#487 的新增行不相邻。
