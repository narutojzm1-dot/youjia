# REQ-20261002-004：大鹅与其它动物的动作和姿态

- 日期：2026-10-02。
- 用户的新要求：「那个动物的动作太少了，包括大鹅的姿势也很少，有卧着的才对，我看目前都是一直翅膀伸开的。」随后明确产品美术定位：「我们这个游戏有个定位，每一帧都是精致的绘画效果，目前来看，还是保持了的。」
- 决策：**已批准**增丰富动物姿态，不能降低当前绘画质量；原设计里张翅的大鹅并非删除对象，但它不能成为休息和安静站立的唯一外观。
- Owner：`MANUS-CONTRIBUTOR`（承接用户此前授权的玩法/可玩性自主开发）；[issue #33](https://github.com/narutojzm1-dot/youjia/issues/33)。旧有 `docs/decisions.md` 的主分支乱码见 [issue #31](https://github.com/narutojzm1-dot/youjia/issues/31)，故以保真增补文件记录并待维护者修复后并入，不覆盖旧历史。

## 首个可独立验收切片：大鹅作息姿态

现有运行时 [cast_v2/goose.png](../../assets/holiday/characters/cast_v2/goose.png) 是已获批准的白鹅张翅、张嘴原画（1254 方画布），原有旧版小图不是游戏正在加载的资源。新素材应以这只鹅的白羽、橙喙、表情、笔触、颜色、朝向和游戏背景光感为统一参考，新增**收翅安静站立**及**伏卧休息**两幅真正的完整透明画作，不能用程序拉扁原画、剪切低清照片或把随便一张白鹅照片混入水彩场景。脸和羽毛允许随姿势自然改变，但玩家能认出是同一只鹅。新画有准确的贴地锚点和完整剪影，在画面里的尺寸与原画合理相邻，图像四边有空白，不能漏出底板或溢出翅膀；原图保留作为活动/警觉时的现有表情。

鹅的原作息已有 `wander`、`graze`、`rest`，但之前都显示同一张张翅图。以有意图的节奏切换对应画面：行走/警觉沿用张翅原图，安静时收翅，伏卧时身体贴地；短时视觉变化不改变导航、碰撞、鱼投喂距离或已收相册。减弱动效下保持静态清楚的帧，不靠反复闪烁。必要时在正式版本实玩校准切换频率，不能让所有动物机械同步表演。
