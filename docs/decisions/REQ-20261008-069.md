## 问题

在布置面板按确认、或从背篓把圆石 / 松果 / 落羽拖到亮圈里，存档确认后小物就凭空出现在屋前 / 篱边 / 塘边小路，没有任何「放下了」的反馈。手机上画面小、小物只有二三十像素，玩家得盯着找才知道是不是放成了。

## 决定

- 某处**新摆上**小物（或换成另一样小物）、存档确认后，小物脚下泛一圈很淡的暖墨椭圆圈：墨色 `5c4533`，环线 42% → 0、内填 12% → 0，1.5px 抗锯齿；0.5 秒内从 9×3 扩到 22×7.5（道具本地坐标，随院内远近同比例缩放），然后自己移除。
- 圈画在小物正下方一层（z = 小物 − 1），圈心贴近小物下沿。
- **小物本身不动**：位置、大小、透明度都不改，所以布置时的遮挡判断、照片取景都不受影响；圈是普通 Node2D，不是照片会记录的 `YardPropVisual` / `Sprite2D` / `Line2D`，放好那一下拍照也只记一个小物、不记圈。
- 不泛圈的情况：读档后第一次重建、同一份布置重复刷新、同一处只微调偏移。收回小物时，那处还在走的圈立即撤掉；同一处快速放 / 收 / 放只留一个圈。
- 布置编辑会暂停小院，圈用 `PROCESS_MODE_ALWAYS` 照常走完。低动效（`ui.reduced_motion`）下圈固定 17×5.8 不扩大，只淡出。
- 不改：布置面板、背篓格子 / 拖放、`yard_prop_visual.gd`、`main.gd`、`yard_world.gd`、存档与库存事务、摆放位置。
