## 问题

`hold_hotbar.gd` 选中格样式在 `place_armed` 为 true / false 时相同。#605 取消后保持解除武装之后，玩家无法一眼看出「点地投放」是否已武装。

## 决定

- 选中 **且** `place_armed`：保留 `SLOT_HOT` + 2px `SELECT_EDGE`，并在底边加 3px 墨色武装角标（`ARMED_ACCENT_PX`），武装 ≠ 仅选中。
- 选中但未武装（草束默认，或用户点格解除）：仅 `SLOT_HOT` + 2px 描边，**无**角标。
- 未选中：不变。
- 提示：武装时追加「点地放下」/ `tap ground to place`；选中未武装追加「再点一次，可点地放下」/ `Tap again, then tap the ground`（避免玩家文案用「武装」）。
- `_apply_cell_style(cell, selected_slot, armed)`；`_set_armed` / `_set_selected` 重绘选中格。
- 新建 `test/hold_hotbar_armed_style_suite.gd`（SceneTree）；**已**登记到 `tools/verify_daily_life.sh` 与 `tools/lib/godot_suite_completions.tsv`（紧接 `hold_hotbar_mount` 之后；#617 仍负责在 `painted_blink` 之后追加 `yard_decor_spot_at`）。
