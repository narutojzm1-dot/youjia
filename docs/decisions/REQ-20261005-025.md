# REQ-20261005-025 底部通知垫纸片：前景草石上也看得清

- Agent-ID: `GROK-CONTRIBUTOR`
- 日期：2026-10-05

## 背景

#276 修订 3 的 Web 复测里记过一条旁注：底部通知（例如“跑了。没关系。”）在阴天背景上对比度低。原生 4.7.2 实际渲染复核后确认，问题不只在阴天：通知是一行没有底的棕色字（`INK #5b4637`），正好压在画面最下方的草、石头和池边花丛上，晴天/阴天、1280×720 和 844×390 都难认。

## 决定

给 `Main._notice` 垫一块贴合文字宽度的半透明纸片：

- 底色复用现有 `PAPER #fff6e8`，alpha `0.88`；描边复用 `APRICOT`，alpha `0.55`、1px；圆角 14。
- 纸片宽度 = 当前文字宽度 + 两侧 14px 内边距，最宽仍是原来的 `±min(220, 屏宽/2−20)`；超出照旧换行。钓到鱼 22px、空闲提示 18px 这些后设字号在下一帧自动重新贴合。
- 换行变高时向上长（`grow_vertical = BEGIN`），底边留在原位，不压住竖屏下方“翻开手帐/阴天”按钮。
- 字色、字号、出现位置带、显示时长、关闭条件、点击穿透都不变。纸片没有动画，低动效不需要分支。

## 不做

- 不改通知文案、本地化、出现时机，不改 HUD 其他控件，不改 `YardWorld`、钓鱼/携鱼规则、存档或资源。
- 不改 `tools/verify_daily_life.sh`（本通道的文本 API 会把它的可执行位改成 100644，见 #276）；新 suite 请合入方挂入 daily，本地已按挂入后的列表完整跑过。

## 验收

1. `test/notice_paper_suite.gd` 三个视口（1280×720、390×844、844×390）共 49 项全过，退出码 0；同一 suite 在当前 main 上 12 项失败（无纸片、宽度不贴合、不重新贴合、不向上长）。
2. WCAG 对比：纸片叠在纯黑上时 INK 对比度 6.28:1（≥ 4.5）。
3. 原生 Xvfb + opengl3 实际渲染前后对比见 [体验记录](../playtests/2026-10-05-REQ-025-notice-paper/README.md)。
