## 问题

院内布置面板（`scripts/ui/yard_decor_panel.gd`）的三处位置按钮永远只写「屋前 / 篱边 / 塘边小路」。玩家要知道哪里已经摆了东西、摆的是什么，只能一个个点过去看状态行；小物按钮突然整排变灰（因为选中的位置已经占了）也看不出原因。摆了两三件以后，挪动或收回某一件要先猜它在哪。

## 决定

- 新增 `slot_label(spot, place, en)`：存档里这处已有小物（`value.places[spot].find_id` 是三种小物之一）时，按钮写两行「屋前\n圆石」/ "House\nStone"；空位写原名。
- 只看已保存的摆放：未确认的预览（半透明）不改位置名；保存中仍显示已保存的那件（位置照旧变灰）；收回后立即恢复原名；存档里缺 `find_id` 或是未知物品时退回原名，不猜。
- 小物名与小物按钮同一套（圆石 / 松果 / 落羽，Stone / Cone / Feather）。
- 第二行让三处按钮一起略增高（同一行等高，仍 ≥44px）；面板仍按 REQ-055 贴合内容，放不下时照旧滚动。
- 不改：按钮可用性、选中 / 悬停 / 不可用样式（REQ-054）、触屏点按、微调与确认逻辑、存档协议、`main.gd`。
