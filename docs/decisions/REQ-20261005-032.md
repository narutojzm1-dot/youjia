## 背景

`scripts/manus/open_source_licenses.gd` 在非 Web 路径里给 TextEdit 写死 `custom_minimum_size = Vector2(560, 320)`，再 `popup_centered()`。实际窗口约 576×378：

- 390×844、360×640、320×568：宽 576 大于屏宽，左右被裁。
- 568×320、640×300、844×390：高 378 大于屏高，底边（含 OK）掉出屏幕。
- 1280×720：放得下。

Web 导出点同一按钮会打开 HTML，不受影响；原生窗口 / 桌面小窗 / 非 Web 预览会看到裁切的声明框。

## 决定

只改 `scripts/manus/open_source_licenses.gd`：

- 新常量 `DESIGN_TEXT_SIZE = Vector2(560, 320)`、`VIEW_MARGIN = 12`、`CHROME = Vector2(16, 58)`。
- 新函数 `_fit_text_size(viewport_size)`：文字区宽高 = min(设计值, 视口 − 边距 − 标题/按钮 chrome)。
- 新函数 `_clamp_dialog(dialog, viewport_size)`：`popup_centered()` 之后把窗口钳到视口 − 24px 并重新居中，避免 chrome 估算误差仍出屏。
- Web 分支、文案拼装、只读/换行、确认关闭逻辑不变。

实测（钳位后）：390×844 对话框落在边距内；568×320 完整可见；1280×720 仍接近设计 560×320。

## 不做

- 不改 `scripts/main.gd`、暂停页、确认页、标题排版、#392/#394、Web HTML 声明页、`tools/verify_daily_life.sh`、`docs/requirements.md`。
- 新 suite 请合入方追加到 daily 列表末尾；本通道不改 shell（可执行位见 #276）。

## 验收

1. `test/licenses_dialog_fit_suite.gd` **120 项全过**（9 个视口开一次 + 改尺寸后再开 4 次）。检查：对话框打开、TextEdit 最小尺寸等于 `_fit_text_size`、窗口完全落在视口内侧 ≥12px、居中、标题不变、只读换行、正文含 Godot Engine；大桌面保留 560×320。
2. 未改脚本时探针：7 个视口里 **6 个出屏**（仅 1280×720 正常），窗口仍是 576×378。
