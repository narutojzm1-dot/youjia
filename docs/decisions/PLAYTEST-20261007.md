# 2026-10-07 用户实玩反馈与验收更新

来源：用户13:19项目邮件回复；CODEX-LEAD本轮已读。统一跟踪[#535](https://github.com/narutojzm1-dot/youjia/issues/535)。这是当前主线验收要求，不因旧测试通过而忽略实际体验，亦不将体验描述直接冒称已查明的代码根因。

1. **天气**：核查晴天/阴天原画、绑定、过渡与遮罩，消除实际体验差异不明显的问题。
2. **画幅和风格**：小院与近郊统一全画幅表现，以近郊清晰、明艳为方向，消除小院缩在中间和薄雾感；横竖屏、可走边界和照片取景分别验。
3. **近郊自由度**：道路上可灵活移动，溪边发现/采集有可理解入口；需普通操作走到、发现、拾取、回院和重开，不以代码存在代替可玩。
4. **双路线与透视**：画中两条路线均可走，北向深入远景人物适当缩小；同行动物、返院与保存同验。
5. **速度**：协调小院人物/动物与近郊的视觉移动速度，消除小院不自然的缓慢；不能只比较未考虑画面缩放的数值。
6. **动物主场地**：各有主要日常活动区域，平时自然活动；引到一起后可发生故事，不为故事常驻拥挤；取食吸引、牵引、回归身份保持。
7. **环境声**：默认降低，滑块最大时实际输出限制为旧最大值30%，不是只把默认滑块设30%；开关/暂停/旧满值选择/浏览器与原生均不能绕过。
8. **场景音乐**：近郊与小院有能听出的差别，跨场景切换、暂停、重开和连续开关稳定；未真实听验不称听感完成。

## 第一片：环境声上限

当前实现确认：Ambience总线原始满值0 dB，滑块直接乘0..1，无额外上限。新片在共享总线应用0.3线性系数，原生播放器和浏览器BGM的有效增益计算共同读取它；滑块保持0..100%语义，默认50%对应旧最大输出15%。保留当前选择值和静音/暂停规则，不改声音素材，不把该片当作第8项场景音乐完成。

初步排查还看到动物日常speed被覆盖到10–23，近郊已有分支道路几何；两项都仍需实际体验定位与改进，不宣称仅凭静态发现解决。
