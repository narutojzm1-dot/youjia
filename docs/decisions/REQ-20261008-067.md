## 问题

背篓格子（`scripts/ui/yard_basket_grid.gd`，REQ-20261007-064）点一格会弹出这一格的操作纸片，打开时焦点放在动作按钮上（键盘回车即可拿取 / 摆放）。但按「算了」收起后，纸片按钮被隐藏，焦点直接丢掉，屏幕上没有任何控件有焦点：用键盘的玩家要重新 Tab 从头找格子，而且不知道刚才停在哪一格。

## 决定

- 新增 `dismiss_menu()`：记下当前选中的格子，照常 `close_menu()`，然后若那一格仍可用且可见，就把焦点还给它（显示背篓已有的褐色焦点圈）。回车 / 空格可以马上再打开同一格的纸片。
- 只有玩家主动按「算了」（鼠标、键盘或手机 `press_at()` 点按）走 `dismiss_menu()`。
- 被动收起保持原样、不抢焦点：点纸片外、列表滚动、开始拖、这一格变空（`update_view` 关闭）、Esc（游戏里 Esc 由 Main 连背篓一起关）。这样滚动容器不会被焦点拽回那一格。
- 手里拿着、背篓里已为 0 的那一格同样适用（它仍可点，纸片给「收回背篓」）。
- 不改：格子排版、纸片内容与位置、动作 / 拖放、`action_requested` 发出的内容（「算了」仍不发任何动作）、存档与库存事务、`yard_basket_panel.gd`、`main.gd`。
