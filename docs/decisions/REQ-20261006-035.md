# REQ-20261006-035 标题页「开源软件声明」链接各态在浅色纸卡上看得清

- Owner: `GROK-CONTRIBUTOR`
- 日期：2026-10-06
- 来源：[#413](https://github.com/narutojzm1-dot/youjia/issues/413)（CODEX-LEAD 发现；GAME-PM 在 [5999714180](https://github.com/narutojzm1-dot/youjia/issues/413#issuecomment-5999714180) 按用户「界面开发交 Grok」授权拟交 GROK-CONTRIBUTOR）。本 PR 即接收回执。原 Owner CODEX-LEAD-ASSISTANT 未开工、无分支；不碰其 382 的 `_input`/modal/slider。在 main `cdec7a6`（含 #432、#433/REQ034、#427）上用原生 Godot 4.7.2 headless 实测。

## 背景

标题页的声明链接由 `Main._text_button()` 生成：`flat = true`，只覆盖了 `font_color`（`MUTED` #8a7060）和字号。其余各态全部落回 Godot 默认主题：

| 状态 | 原颜色 | 对纯 PAPER #fff6e8 | 对 84% 纸卡叠黑底 #d6cfc3 |
| --- | --- | --- | --- |
| 普通 | #8a7060 | 4.29:1 | 2.97:1 |
| 悬停 | #f2f2f2 | 1.04:1 | 1.39:1 |
| 键盘焦点 | #f2f2f2 | 1.04:1 | 1.39:1 |
| 按下 / 悬停按下 | #ffffff | 1.07:1 | 1.55:1 |
| 焦点框 | #cccccc（默认） | 1.50:1 | 1.04:1 |

纸卡是 `PAPER` 84% 不透明叠在标题底图上，实际底色落在两列之间。Web 上点链接会在新标签页打开许可页；回到原标签时链接通常仍处于焦点/悬停态，于是看到的是近白字叠浅纸卡，与 #413 截图一致（推断，未在真实浏览器复现）。普通态本身也略低于小字 4.5:1。

## 决定

只改 `scripts/main.gd` 的 `_text_button()`（及两个新颜色常量）：

- 普通 `TEXT_LINK` #6b5242：PAPER 上 6.73:1，叠黑底 4.66:1。比 `INK` 浅一档，保留「次要链接」层级。
- 悬停 / 悬停按下 `TEXT_LINK_HOVER` #3d2d23（与主按钮悬停字同色）：12.26:1 / 8.49:1，比普通更深。
- 焦点 / 按下 `INK` #5b4637：8.25:1 / 5.71:1。
- 焦点框：2px `TITLE_ACCENT` #a85d28 描边、不填底、8px 圆角，PAPER 上 4.60:1、叠黑底 3.18:1（非文字 ≥3:1）。
- `focus_mode` 显式为 `FOCUS_ALL`（与原默认一致）。
- 字号（14 / 短横屏 12）、文案、顺序、标题列排版（REQ-031）、纸卡（REQ-028）、原生许可窗口（REQ-032）、Web 外链行为都不变。

## 不做

- 不改主按钮、相册、暂停、确认面板或其他屏幕的配色；不改 `_input` 触屏分发、modal、slider（382）、探索 cleanup（#427）、相册适配（REQ034）、#432 标题启动逻辑，也不顺手修上面那两项回退。
- 不改 `tools/verify_daily_life.sh`、`docs/requirements.md`；新 suite 请合入方追加到 daily 列表末尾。
- 不冒真实浏览器/手机截图验收；只做原生 headless 主题取值与几何。

## 验收

1. `test/title_licenses_link_contrast_suite.gd` **340 项全过**：568×320、640×300、844×390、1280×720、390×844 × 中/英。每个视口检查链接在纸卡内、可见、flat、可键盘聚焦、字号不变；五个文字状态在纯 PAPER 与纸卡叠黑底两端都 ≥4.5:1；悬停比普通深；焦点框无填充、四边 ≥2px、两端 ≥3:1；再按真实路径聚焦 → 点链接 → 原生许可窗口打开 → 点 OK 关闭 → 回到标题、链接仍可用。
2. 未改脚本时同一 suite **130 项失败**（各态对比 + 焦点框）。
3. 改后（隔离 XDG 用户目录，与 daily 同法）`licenses_dialog_fit`、`album_short_landscape`（52319）全过；`title_short_landscape` 1541 项中 1 项失败（568×320 点「开始」进院子）、`title_card` 251 项中 1 项失败（开玩后纸卡隐藏）。**这两项在未改的 main `cdec7a6` 上同样失败**，与本改动无关。在上一版 main `96f090a`（已含 #432）上，本改动下这两个 suite 及 `ui_interaction` 全过，所以回退出现在其后合入的 #433（REQ034 集成）或 #427（探索 cleanup）之间；具体是哪一个未核实，请 CODEX-LEAD 看。
