## 问题

小院里收杆钓到鱼时，塘面上会扩散 3.2 秒的庆祝环。环的颜色是模板留下的霓虹色：小鱼青蓝 `(0.35, 0.78, 0.95)`、中鱼亮蓝 `(0.28, 0.58, 0.95)`、怪鱼紫 `(0.55, 0.40, 0.92)`（饱和度 0.56–0.71），内环是冰蓝白，飞散的小点是饱和蓝。环上方 48px 还有一块深海军蓝圆盘 `(0.12, 0.22, 0.38)` 加金边——里面什么也没画，是一个空徽章。整套在毛毡动物 + 水粉院子里像科幻 HUD 的特效，和院里其他纸 / 墨 / 水彩反馈（拍立得纸签、背篓暖纸、宠物水彩心）不是一个画风。

## 决定

- 只改颜色和徽章内容；所有半径、透明度、时长、扩散曲线、小点数量、徽章出现时段、低动效静止姿态（`celebration_pose`）都不变。
- 外环：暖金 `f0c46a`（原 `ffdb59`，稍收一点亮度）。
- 中环 / 水纹填充按鱼的种类，换成低饱和的塘水色（饱和度 ≤ 0.4）：小鱼 `8fbfb4` 浅塘绿、中鱼 `6f9fae` 深塘蓝灰、怪鱼 `a58fb3` 灰紫。三种仍分得出来。
- 内环：纸色 `fff6e8`（Main 的 PAPER），不再是冰蓝白；中心闪光 `ffe7b0` 暖奶油。
- 飞散小点：用该鱼塘水色提亮 25%，不再是饱和蓝。
- 徽章：深蓝空圆盘换成纸色圆签（`fff6e8` 92%）+ 2px 墨边 `5b4637`（Main 的 INK），里面画一条侧身小鱼（鱼身、尾巴用该鱼塘水色填充，1.4 / 1.2px 墨线勾边，墨色小眼睛）。鱼整条在徽章半径 0.8 以内。墨对纸约 8:1。
- 未知鱼种回落到小鱼的颜色（与原 `match` 默认分支一致）。
- 不改：钓鱼逻辑、收杆判定、HUD 钓到通知、拍立得、携带 / 背篓、存档、`yard_world.gd`、`main.gd`；目标弧（`_draw_pet_arc`）和其他反馈也不动。
