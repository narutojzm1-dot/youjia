## 问题

`scripts/ui/yard_basket_panel.gd` 的纸面设计是 `min(520, 屏宽-24) × min(620, 屏高-24)` 居中，四边各留 12px。用 Godot 4.7.2 headless 实测：

1. **280 宽竖屏英文**：「Curious fish  × 1」+ 104px「Take one」按钮的最小宽度把纸面撑到 276px，纸面离屏幕左右只剩 2px（应为 12px）。中文「奇怪的鱼  × 10」在 280 宽也会把纸面撑过 256px。
2. **矮横屏清单窗太矮**：568×320 清单滚动区只有 146px、640×300 只有 126px（保存失败时 94 / 74px），10 行内容一次只露约 3 行；24px 标题、8px 间距和一行说明句占了地方。
3. （实现中发现）若第一次打开就在矮横屏、说明句从没排过版（宽 1px、最小高 500px+），转到竖屏时纸面会被撑到 644 / 852px 高、顶到或越出屏幕上沿。

## 决定

只改 `YardBasketPanel` 的排版：

1. 清单里的名字标签（三件探索所得、五行鱼 / 草 / 米、手里拿着）改为按词折行：放不下时在名字里折到第二行，不再撑宽整张纸。
2. 纸面宽度不足 280px（屏宽约 304 以下）时，每行「拿一条 / Take one」按钮从 104 收到 88px（文字仍放得下，高度仍 44px），名字多出 16px，中文不用折行；英文「Curious fish  × N」在 280 宽折成两行。
3. 纸面高度 ≤ 420px（矮横屏）时进入紧凑排版：标题 24→19px，列间距 8→4，行间距 6→3，并省掉那句说明「钓到的鱼、散步带回的小物，都收在这里。」。**保存中 / 未确认 / 失败 / 读不出库存的提示和「再确认一次」按钮照常显示。**
4. 纸面最小尺寸变化（说明句显隐、折行）时下一帧再排一次版，避免隐藏期间的旧高度把纸面撑出屏幕；只在真正变化时改主题覆盖，不会每帧重排。

结果：568×320 清单窗 146→191px，640×300 126→171px，844×390 →261px；280 宽纸面回到 x=12、256px 宽。高于 420px 的纸面（所有竖屏、1280×720 等）标题、间距、说明句、尺寸位置与改前一致。

不改：文案、颜色、纸面样式、按钮高度、44px 触控目标、滚动 / 触摸手势、库存 / 存取逻辑、保存、`scripts/main.gd`。
