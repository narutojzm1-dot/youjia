# 2026-10-03 · REQ-011 鹅与羊驼安静共处关系切片

**阶段：** 候选实现分支验证；尚未合入或发布。制作人已确认这一首片。该切片只包含玩家牵引羊驼靠近大鹅、安静共处后写一次关系记忆，以及后续偶尔延长羊驼停留。

## 验收边界

- 牵引期间羊驼从鹅周围 128 世界像素外进入安全近距后才记录玩家来源；开始时已靠近则需牵离再带回。
- 放开后，鹅与羊驼都需处于吃草/休息状态、各自站在可走地面并维持 1.25 秒；否则不产生关系记忆。
- 事件只结算一次；后续行为以 10% 机会延长羊驼现有的安静停留。选择保持随机，每次相遇不保证发生。
- 记忆通过 SaveStore v5 的单一白名单标记保存；v4 档缺字段时加载为空，原假期/相册/植物/钓鱼数据保留。
- 无提示、任务、关系数值、缺席衰退、新资源、照片、CG 或 REQ-012 摄影逻辑。
