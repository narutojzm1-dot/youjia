## 玩家可见行为

夜间点击原房门，沿既有门廊走入房间，持久化睡眠成功后迎来次晨。
每三个游戏天中伪随机选一个早晨；只有这天实际在屋里醒来、且不下雨才
演出阳台活动。其余照常由正门出门，不因未睡觉而补演或奖励。
五项轮换：伸懒腰、站着打盹、喝咖啡、远眺、刷牙；各有两张独立原画关键姿态。
移动沿已有逐帧行走动画，脚底锚点固定，栏杆与花箱在人物前方。

二楼门打开→人物显现于门内阈值→走到栏边→活动6.5秒→走回同一门→
进入并关门→在室内下楼→楼下门打开→走回原门前小路。楼下玩家在二楼
代理活动时隐藏，并未把可行走地面扩展到屋顶。点击地图或方向输入可以
提前结束活动，仍走完返程，不穿墙传送到草坪。暂停冻结；减少动态保留
清晰静止姿态与可结束的路线。温暖室内复用既有卧室原画，房门复用原画
窗扇，晴阴遮挡层和公共晨光保持一致。
