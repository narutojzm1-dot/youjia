# 磨粉候选夜间归位互等：定位与限定修复

CI [38402461163](https://github.com/narutojzm1-dot/youjia/actions/runs/38402461163) 对远端 `7d16a4e9fa1131629489a8bcf8725b1e6b16577f` 在 `large_animal_shelter_suite` 报出 4 项失败：马与羊驼没有回到自己的户外夜间休息区。随后在本地 `321735f6a7f17cf368cb7740f2690ac9024f79e6`（与远端 `8b08e0540a5195627cc880f27b976fb923ba6a5c` 同树）隔离存档完整复现，未以超时或随机波动掩盖失败。

雨后晴天自然游走结束时，羊驼停在 `(844.7318,528.4039)` 的院门入口窄道；夜间队列将羊 `sheep_b` 锁为当前行动者，但该羊没有可通过入口的路径，队尾羊驼又被禁止先走回自己的休息区。移除磨盘的**诊断查询**或替换七个试探磨盘坐标均未解开当前路径；仅从查询障碍集排除羊驼后才出现合法入圈路径。磨盘加入后改变了此前游走结果，暴露的是此单队列互等，不能靠挪磨盘碰运气处理。

修复仅改 `scripts/game/yard_shelter.gd` 调度：入圈者在原有 0.6 秒重寻路节点仍无路时，先证实某个待归位的马/羊驼确实挡住路径，再确认它保留全部实体障碍时能走到自身目标，才让它先完成自己的归位。真正运动仍使用全部碰撞；牵行、骑乘、玩家姿态所有权不被接管。外归角色不能反向让出优先权，避免双方来回切换。磨盘位置、站位、工作点、碰撞半径、共享导航、素材和存档格式均未改变。
