# 动物同行候选体验

Owner CODEX-LEAD，#503 WORLD-COMPANIONS，基于 main 4139a36e90741741e6b48b22714f82b01e27babd。本地候选证据保留如下；PR510 已合入并完成公开包核验，最终状态与公开实玩见 [public/README.md](public/README.md)。

## 玩家行为

牵着草泥马点击实际出院小路，或走到小路端选择“出门走走”，会带同一只草泥马出院。未牵绳时，出发瞬间在玩家 120 院内像素范围内的陆行动物有 35% 概率同行，每趟最多一只；牛、羊、马、鹅、草泥马使用既有稳定身份，鸭留在池塘。没有附近动物就独行，不远程召唤。牛回院后不会变成绳牵跟班。

抽签和绳牵身份只在建立旅程时确定，随原旅程记录保存；重复出门、等待保存、存档重试不重抽。旧记录没有同行字段仍按独行恢复；未知伙伴或扩展字段原样隔离，不能静默改成另一只或丢掉字段。回院复用原 YardWorld 节点；途中重启按现有契约安全回院，伙伴摆在合法返院位置，不创建可堆叠活物库存。绳牵状态在普通往返保持，重启后回院不强制恢复牵绳动作。

院外跟随复用 CastArt 完整原画和 FeltActor 已有脚点/步态，沿 NearPathLayout 道路及小幅路肩间距走动，不穿越溪流；绳端使用人物原画手部帧锚和草泥马项圈锚。没有新角色画、口型、叫声或动物管理 UI。

## 普通浏览器输入

http://127.0.0.1:8765/companions/index.html，IAB，无游戏/存档注入。

1. 1280×720 正常进院，点击移动中的草泥马并牵起，点击左下出院小路；实际进入近郊，沿路走到中段，草泥马跟随并停下，绳连到人物手与动物下颈。
2. 390×844 同行画面中回院按钮可用，点击后人物与原草泥马回到门口，绳牵保持；再次出院，在途中刷新页面，正常进院后伙伴也回到院内，再次点击可牵起。

最终截图以 web-final 开头；web-reopened-390 为最终候选恢复画面，web-return-390 为路肩微调前同一返院逻辑。牛概率同行由隔离原生 Main 的已知种子验证，不冒称本次普通浏览器恰好抽到了牛。响应式窗口验证不等于实体手机触控实测。没有声称新增音频听验。
