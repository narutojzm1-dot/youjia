# 快捷栏格子的键盘焦点圈（CURSOR-CLOUD UI 维护）

## 问题

#762 让 Tab 能走到手持快捷栏五格，但格子的焦点圈很难看出来：

- 焦点圈是 2px 的 `#916d49`，正好画在格子原来 1px 的 `#b88a61` 边上。两种棕色对比只有 1.53:1，看上去只是“边粗了一点”。
- 手里拿着的那一格本来就是 2px 墨色 `#5b4637` 边，焦点圈用的也是同一种墨色、同一位置，Tab 到这一格时完全看不出变化。

## 改动

`scripts/ui/hold_hotbar.gd` 的格子焦点样式改为：

- 圈画在格子外面（外扩 3px、宽 2px），与格子边之间留 1px 纸缝，不盖住选中、武装底边和落点描边。
- 颜色用底栏按钮焦点圈同一枚赭色 `#a85d28`。在快捷栏纸面上对比度 4.6:1；纸面半透明时按最暗（叠在黑色上）算也过 3:1。
- 外扩不超过格间距的一半，不会压到相邻格；也留在快捷栏纸面以内。

只改焦点样式，选中、武装、落点和格子大小都不变。

## 回归

新增 `test/hotbar_focus_ring_suite.gd`（1205 项），在 390×844、844×390、1280×720 三个视口下，对五格在空手、拿草（选中）、拿鱼（选中并武装）、背篓配置时的落点提示四种状态分别检查：

- 焦点圈不填色、不透明，四边至少 2px。
- 圈画在格子外，并留出纸缝。
- 外扩不超过格间距的一半。
- 对快捷栏纸面（实色和最暗叠色）对比度至少 3:1。
- 圈留在纸面和视口以内，焦点能落上。

改后全过；在 main 的旧样式上失败 240 项（圈贴在格子边上、画进了格子里）。其余快捷栏、HUD 键盘焦点、按钮焦点对比和背篓格子套件全部通过。
