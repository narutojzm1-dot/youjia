## 行为

牛在原有静止咀嚼姿态时，以独立随机间隔4.5–11秒进行0.30秒闭眼/短停/睁眼。现有轻呼吸保留；不是新增整身缩放。只对两个眼部矩形使用闭眼原画，保留原alpha、身体、嘴、脚位和朝向。走动、抚摸回应、领出/近郊、入棚卧姿及减少动态立即归零。暂停不推进；异常长帧不补播。随机源独立，不消耗玩法随机数。没有改保存格式，照片仍使用规范原画，不另存随机眨眼瞬间。

首片只覆盖牛的chew静止原画，牛的其他姿态、其他动物与主角步态均未冒称完成。补充原画1,242,947字节，1254² RGBA约6.0MiB，shader只在闭眼量大于0时读取额外纹理。生成来源、完整提示和SHA256见provenance.json；没有重绘/覆盖原文件。
