# 动物翻出隐藏物：本地候选

Owner CODEX-LEAD，WORLD-ANIMAL-FINDS，#503/#504。基于 1a1e671f35b4ee78adbe80cac2519253c0d33227；最终 PR/CI/公开发布尚待，不把此候选称为线上版本。

## 已实现的完整行为

近郊增加一处路边落叶，原四处普通探索与三件携带上限保留。独行或带其他动物只能看落叶；同行草泥马到场后低头翻找2.4秒，挪开落叶，显现一枚松果。动作完成的事件由 Host/Session 验证冻结的动物身份及当前位置；保存确认后才显示物品与拾取入口，UI不能自行指定奖励。玩家可带上、满篮交换、放回、离开或回院，所得进入原来的大背篓。

隐藏结果复用 offers/taken/carried，不增加另一份物品账本或新存档字段；重复揭示不重抽/不重发。写入未知时不重复提交，明确拒绝后再次观察可重试；未确认时不开放拾取。途中重开继续沿既有安全返院和一次结算路径；旧路线没有新停留点时，已经带上的东西及来处仍保留。

动作使用同一草泥马完整低头原画，按背部/蹄距校准0.91源比例，脚点(475,1063)、低头绳端(837,737)，而不是按下降后的头顶高度放大整只动物。接近阶段仍沿现有道路走，低头时全身不形变；原画落叶等比绘制，翻找后挪开。动作结束后走回主人侧后方，避免重叠遮住人。暂停、失焦、继续走和回院均可打断；低动效保留静态低头阶段与确认后的显现。

## 实际画面与体验边界

`native/` 是生产 NearPathScroll + MemoryStore 的受控原生渲染，用于审查低头完整姿态、脚点/绳端及最终横竖布局，不能冒称普通玩家输入。`web/` 为本地浏览器普通输入，无游戏/存档注入。

普通浏览器完成：牵起草泥马→实际院门出院→点击路面走至落叶→观察后显现松果→带上→回院大背篓松果增至2→刷新重开仍为2。最终候选又在390竖屏观察/拾取，显示“篮子里的松果是在这里带上的”；568短横屏发现字幕遮住人物上部后改为左侧纸片，拾取短展示按实际纸片横向范围避让，原有场景字幕布局不变。早期截图不冒称最后横屏修正版本，最终实玩截图按实际阶段保存。

响应式浏览器不等于实体手机触控；未知写入是受控注入，不冒称真断电；没有新增音频听验。beibei、村边新地图、鸡成长及乌龟/鹅关系仍未完成，本片不关闭总单。

最终短横屏普通输入已确认左侧字幕不遮人物，拾取与回院按钮完整可用；途中携带刷新后自动安全返院，背篓松果由2变3，没有重复增加。浏览器本轮捕获 warn/error 为空。出院提示的旧 actor.llama 文案键已改用现有 target.<actor_id>，专项新增真实显示名称断言（92项通过）。
