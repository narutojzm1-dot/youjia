## 院里底排三枚小按钮

- **修前**（`before-yard-280x653.png`）：竖屏三枚小按钮平分 `(宽 − 80) / 3`，280 宽只有约 67px；「翻开手帐」文字需 96px，按钮被文字撑宽，压住「阴天 / 大太阳」约 9px，整排右端到 273，越过 20px 边距。320 宽间距只剩 4px。英文 280 宽同样溢出。
- **修法**（`scripts/main.gd` `_chip_row_plan`），分三档：
  1. 平分放得下：不变（390 宽、英文 360 宽、横屏等与 main 逐像素一致）。
  2. 只差几像素：其余两枚仍平分，只让放不下的那枚变宽，间距从 20 往 10 收。360×640 中文「翻开手帐」96px 对平分 93.3px：96 / 93.3 / 93.3、间距 18.7。main 上它同样被文字撑到 96、间距 17.3 与 20，所以只是中间那枚右移约 1.3px。320 宽为 96 / 80 / 80、间距 12。
  3. 仍放不下（280 宽）：按各自文字宽度排、间距 10px，再不够把左右内边距从 16 收到 8px：84 / 68 / 68。
  - 天气按钮按所有天气里最长的名字留宽，换天气、切语言不必重排。
- **修后**：`after-yard-280x653.png`、`after-yard-320x568.png`、`after-yard-360x640.png`（夜里截的，院景偏暗与本改动无关）。
