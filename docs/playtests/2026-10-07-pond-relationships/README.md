# WORLD-F3 岸边动物关系：在途验收

Owner CODEX-LEAD；需求 #503，资源 #504。依赖 WORLD-F2 PR520 的成年母鸡，乌龟沿用已确认的 beibei 发现/收养身份。

## 已实现

成年母鸡和乌龟在岸边相遇，母鸡搭背短游；大鹅慢慢走近、张翅请求，乌龟不让搭乘，大鹅伸颈啄了个空，乌龟沿岸走回水塘。小鸡阶段不会参与。复用现有动物身份与步速，不生成第二只动物或新增物品。玩家移动、互动、手持食物、暂停/接管使演出让出控制权。

沿用地面身体避让寻路并保留路径节点；为透视比例预留足印空间。大鹅从院子另一端走来可能需要较长时间，最多等90秒，受阻会退出，不能用超时冒充抵达。乌龟返回也以实际抵达判断。低动效移除驮行的装饰摆动。

两个手帐事件：`pond_hen_ride`（慢慢的顺风车）、`pond_goose_refused`（这次没有你的座位）。记录演出中的完整原画，隐藏被替代的单独角色，防止照片重复动物。通过既有相册队列落盘，重复相遇不重复收集。
