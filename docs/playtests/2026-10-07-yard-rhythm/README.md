## 实际缺陷与修复

牛在原区域外吃完地面草后，旧局部采样不能到达原活动范围，动物会停留投食地点。真实库存消费回归先出现明确失败，再加入可绕开动物的回归路径；区域中点被占时尝试其他内部落点，受阻重新寻路。继续投食仍可打断回归，羊驼松绳后保留自由活动，关系故事/牵引优先。不是把动物瞬移回去，也不是吃草后跟随人。

新增区域回归曾发现鸡与牛矩形仍重叠2个场景单位，已移开再验。普通Web观察到第一版beibei仍贴近羊群，又把主要范围向屋前小路下方移动；最终坐标(295,615)，区域(270,600,50,30)。同时修正初始化硬编码绕过beibei配置的位置。
