# 点按打开小鸡照料纸、菜地纸时不画焦点圈（CURSOR-CLOUD UI 维护）

## 问题

在院里点小鸡（或点行动按钮「看看小鸡」）打开小鸡照料纸时，「回到院子」马上画出深色焦点圈。点按玩家看到的是一个像被按住的按钮。菜地纸打开时也一样。这两处的焦点是 CURSOR-CLOUD 在 2026-10-10 加的（照料纸打开即有焦点，方便键盘玩家），当时没有区分点按和键盘。

## 改动

`scripts/ui/chick_care_panel.gd`、`scripts/ui/crop_panel.gd`：

- 记下最近一次按下的是鼠标 / 触屏还是键盘 / 手柄按键（`_input`）。
- 打开时焦点照样交给「回到院子」；点按触发时用 Godot 的隐藏焦点（`grab_focus(true)`），不画圈，键盘一导航就显出来。
- 走过去按空格打开时照常画圈。

做法与背篓格子纸片（#769）相同。不碰 Main。

## 回归

新增 `test/care_pointer_focus_suite.gd`（79 项），走真实 Main，在 1280×720、390×844、844×390 三个视口，对小鸡纸和菜地纸分别检查：

- 先有一次鼠标点击或触屏点按，再由世界发出打开请求（与点到小鸡 / 菜地相同）：焦点在「回到院子」，不画圈；按一次 Tab 后圈出现在纸面里。
- 先按空格再打开：焦点在「回到院子」并画圈；回车关上。

改后全过；在 main 上失败 12 项（点按后都画了圈）。照料纸排版、小鸡照料、菜地、HUD 遮挡、居民气泡、触屏模态、菜单 / HUD 键盘焦点和背篓纸片焦点套件全部通过。

## Web 实玩证据

本分支和 main 各导出一份 Web 版，1280×720 新档进院子，点小鸡或「看看小鸡」打开照料纸：

- `before-click-chick-1280x720.png`：main，「回到院子」带深色焦点圈。
- `after-click-chick-1280x720.png`：本分支，没有焦点圈。
- `after-click-then-tab-1280x720.png`：本分支，之后按 Tab，圈出现。
- `back-button-before-after-tab-crop.png`：上面三张里「回到院子」按钮的放大对照（左 main，中本分支点按，右本分支再按 Tab）。

## 已知限制

- Web 证据只拍了小鸡纸；菜地纸新档第一天不好走到，由套件检查。
- 刚打开背篓时「合上背篓」的焦点圈仍在 Main `_show_basket`（#720 在改），不在本片。
