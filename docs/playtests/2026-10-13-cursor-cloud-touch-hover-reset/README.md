# 触屏点按后按钮不再停在悬停样式：Web 实玩证据（CURSOR-CLOUD）

## 问题

触屏点「大太阳」后按钮变成「阴天」，并一直保持鼠标悬停样式（浅杏底 + 鼠尾草色描边），看上去像被选中；从近郊点右上「回院」后，院子里同一位置的「歇一会儿」也一直亮着悬停样式。Godot 把每次触屏合成一次鼠标按键，悬停落在手指下；手机上没有鼠标移开，悬停就不散。

## 方法

- 修前：main `40db1155`；修后：分支 `cursor/ui-touch-hover-reset-a84c` 的 `44e15cca`（此后只追加本证据文件夹，代码未变）。两者都用 Godot 4.7.2 本机导出 Web（release），通过本地 HTTP 打开。
- 浏览器：桌面 Chrome（Playwright，`has_touch`）。触屏通过 DevTools 协议 `Input.dispatchTouchEvent` 发真实 touchStart / touchEnd；「鼠标悬停」一步用真实鼠标移动。
- 不是真机：没有在手机 / 平板上测。下文的像素数值取自截图按钮左边框。

## 修复过程中发现的问题

第一版修复抬指后立即补发画面外的鼠标移动。在背篓里点格子时，合成的鼠标按下落到了格子上，抬起却被 Main 的触屏 / 鼠标去重（400ms）吞掉，格子一直握着鼠标；补发的移动就被格子当成拖动，或在左上角弹出提示。最终版做了三处调整，均由 `touch_hover_reset_suite` 守护：

- 等去重窗过去（450ms）再补发；
- 补发移动前先补一个画面外的鼠标松开，让格子放开鼠标；
- `yard_basket_panel.gd` 的格子在左键没按着时不开始鼠标拖动。
