# REQ-20261002-009：窗台花箱与手绘蝴蝶（首个可玩垂直切片）

- 日期：2026-10-02。基于主分支 `5c28a4ee261ef92cb8bb042c9020a882e0ae6bdc`；关联[用户确认的 REQ-009 方向](../decisions/REQ-20261002-009.md)、[静态背景互动架构](../architecture/painted-yard-interactions.md)和 [issue #36](https://github.com/narutojzm1-dot/youjia/issues/36)。
- 这次**实装**的是第一处环境热点，不是六处都已完成；其中“改变背景上原有门、窗、栅栏”的替换型底板绘画仍是后续工作。本切片先验证背景不变而蝴蝶、花瓣以独立透明原画轻叠的模式。

## 真实玩法与状态

1. 点中画中二楼窗台**真实花箱形状的多边形**，而不是整扇门或整栋屋子。真实 Web 截图中的花朵中心校准为世界 `(285,275)`，上方玻璃窗 `(285,225)` 明确不命中。世界使用 `YardSceneHotspots.CATALOG` 的同一条 `windowbox` 定义：命中轮廓、`Vector2(253, 494)` 的草坪内安全脚点和 `Vector2(284, 225)` 的局部画作锚点**彼此独立**；玩家不可能走上楼顶。
2. 保持 `YardInteraction.pointer/selected/primary/reach` 的同一动作对象：选中后 HUD 显示“目标：窗台花箱 · 看看花箱”，触屏、行动按钮、空格沿同一目标走到安全点。动物、草、花、池塘现有目标仍优先；牵行、携鱼/草和抛竿期间环境热点不可用。只有**真实走到安全点**才有回应。
3. 每次成功都显示轻薄的水彩飘瓣约 1.8 秒；首次抵达花箱**立即出现同一只蝴蝶的两幅独立水彩画帧**，约 2.8 秒自行离开。玩家观看至 1.3 秒才将这一会话的偶遇计为“看过”；太快离开，下次仍可遇见，同一会话真正看过后只保留花瓣。没有概率刷取、物品消耗、任务计数、相册新条目或存档迁移。
4. 点别处、走开、暂停或进入相册立即撤销短时画层；减少动效时蝶停驻一帧，不强迫玩家等待动态才辨认对象。画层继承晴/阴底图色调，并位于背景之上、地面角色之下；画作来源和哈希见[水彩资产记录](../../art/concepts/scene_hotspots/windowbox/README.md)。
