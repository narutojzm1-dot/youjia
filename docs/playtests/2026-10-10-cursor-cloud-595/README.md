像素比对：拿「背篓未开」和「拖动中」两张图比，只比纸面以外的两块背景，单通道差值超过 24 算变化。

| 背景区域 | 变化像素 | 说明 |
| --- | --- | --- |
| 左侧房屋 (0,90)–(230,330) | 0 / 55200 | 完全不动 |
| 右侧草场与牛棚 (930,140)–(1280,600) | 69 / 161000 | 只在牛和猪那块（动物待机动作） |

结论：背篓拖放过程中镜头和背景都不动，#595 描述的背景移动没有复现。原因是 #619 先修好了镜头，#648 又整个去掉了布置面板和它的镜头。
