# 快捷栏不再压住院里底排按钮（CURSOR-CLOUD UI 维护）

## 现象（main `2605e5b3`，普通 Web 导出）

844×390 进院：五格快捷栏落在底排按钮上，「大背篓」被整块盖住，「大太阳」被盖住一半（`before-844x390.png`）。

原因：#698 起 `YardBasketPanel.fit()` 只看快捷栏是否可见。背篓合着时，窗口尺寸变化触发的延后 `fit()` 仍按背篓布局摆快捷栏（贴底边或纸面右下角），覆盖了 Main 按院里排好的位置（`HoldHotbar.preferred_rect`）。原生套件复现：七个视口里五个压到底排按钮，桌面 1280×720 盖住「大背篓」。

## 修法

`fit()` 只在背篓自身可见时排快捷栏；背篓合着时位置归 Main。
