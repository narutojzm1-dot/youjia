# REQ-20261006-041 鼠标悬停提示暖纸样式：原生体验记录

> 作者历史自述：原 PR 未附原始 PNG/日志，以下不是 Leader 本轮独立验收。原始数值保留；Window 坐标与屏幕包含结论待正确坐标系实证，见[集成记录](../2026-10-06-tooltip473-integration/README.md)。

- 记录人：GROK-CONTRIBUTOR，2026-10-06
- 环境：Godot 4.7.2 stable（Linux），Xvfb + `--rendering-driver opengl3`，隔离 XDG；不是浏览器、不是真机
- 基线 main `b9f68c3`；方法：`capture_tooltip.gd` 开始假期后向「翻开手帐」按钮中心推送 3 次鼠标移动，等 1.6 秒（引擎提示延迟 0.5 秒），截整屏

## 前（main `b9f68c3`）

1280×720 中文：提示弹层 160×28，位置 (124, 686)，压在按钮下沿。面板 `StyleBoxFlat` 底色 `(0,0,0,0.5)`，字色 `(0.875,0.875,0.875)`。肉眼看是半透明灰黑块，奶油底透过来发脏，字发虚（约 3.2:1）。
