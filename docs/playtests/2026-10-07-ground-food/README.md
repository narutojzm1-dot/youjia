## 本片行为

草束可拿在手里、放进背篓、取出、放到合法草地或拾回。钓到的三种鱼沿用同一库存闭环，可以放到地面。地面食物有稳定 ID 和落盘状态；保存确认后才显示移动/移除。牛、羊、草泥马寻找草，鹅寻找鱼，鸭只取自身水面能接近的岸边鱼。多个动物竞争一个物品只消费一次；多个草束聚在院门小路附近能把远处的牛吸引过来，吃草不会把牛切换成人物跟随。牵绳状态优先。
