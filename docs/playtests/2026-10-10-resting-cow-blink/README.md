# #645 卧姿牛局部眨眼

Owner CODEX-LEAD；分支 codex/lead-resting-cow-blink-645，基于 #669 修订 fd702a0284928b2abe660750103174e55cd160a3。

旧眨眼只匹配站立原画，棚内卧姿会停用。本片为cow-rest生成同构图闭眼原画，只在两块羽化眼部区域混合，保留原始卧姿纹理、脚底锚点与透明轮廓。4.5–11秒随机间隔、0.30秒闭眼/停留/睁开。切回站立重新绑定站立眼部坐标；互动、移动、减少动态等既有取消规则继续适用，无存档字段、玩法随机或碰撞变化。

原画由imagegen编辑原始cow-rest.png，要求唯一变化为双眼轻柔闭合、保留1280×1280构图与全部面部/身体/透明边界。原始生成图保留；运行时只采样眼部，不替换整只动物。GPU 640×640实际渲染：2363像素变化，眼区外0，alpha变化0，0/50/100%截图随附。原生painted_blink 106、large_animal_shelter 27、yard_shelter 34、photo_moment_save 48，共215项通过，Web release导出成功。

普通Web localhost:8795，从标题进入晨间小院，棚内实际卧姿牛连续录取160帧、约9.06秒，不注入时间/状态。随附原始帧0/95/97/100与全部帧时间；这不是放大的画廊替代正常游玩。原始160帧暂存本地Temp/youjia-cow-rest-web-frames。GPU图为单独离线美术检查，不能冒称普通Web。

只覆盖牛卧姿局部动作，羊/马/羊驼其他卧姿自然动作仍需后继交付，#645保持开放。正式公开验收另行核验。
