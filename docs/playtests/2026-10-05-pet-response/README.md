## 独审修订：日常待转向不能盖掉回应

独立审查发现正常 `wander/_turn_pause` 会在下一 tick 把动物重新转向旧目的地。修订后回应期间暂停这段转向且保留原计时，回应结束才继续。定向生产类回归新增相反方向玩家、待转向 0.55 秒、真实 tick、回应期朝向与原计时保留、结束后恢复，110 项通过；牛 glance 8 项通过。八态 Web probe 同样设置相反待转目标并推进真实 tick 0.1 秒；结果必须 facing=1、turn_pause=0.55、无心且回应剩余 2.1 秒。
