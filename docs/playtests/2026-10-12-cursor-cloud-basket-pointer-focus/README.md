# 点按打开背篓格子纸片时不画焦点圈（CURSOR-CLOUD UI 维护）

## 问题

在背篓里用鼠标或手指点一格，弹出的小纸片会把焦点交给第一项（例如「拿一把」），这一项马上画出深色焦点圈。点按玩家看到的是“已经替我选好了一个”的框，和旁边按钮不一样，像是被按住了。点「算了」回到格子时，格子上也会亮一圈。

焦点交出去本身是对的：键盘玩家要能接着按（REQ-20261008-067）。问题只是点按时不该把圈画出来。

## 改动

`scripts/ui/yard_basket_grid.gd`：

- 记下最近一次按下的是鼠标 / 触屏还是键盘 / 手柄按键（`_input`，以及触屏统一入口 `press_at`）。
- 纸片打开、点「算了」回到格子、「放进快捷栏」后回到这个按钮时，焦点照样交出去，但点按触发时用 Godot 的隐藏焦点（`grab_focus(true)`）：不画圈，键盘一导航就显出来。
- 键盘打开纸片、键盘按「算了」时照常亮圈。

只改格子组件里这三处交焦点的地方，不碰 Main。

## 回归

新增 `test/basket_pointer_focus_suite.gd`（149 项），在 280×653、390×844、844×390、1280×720 四个视口，对鱼、草束、落羽三类格子用真实的鼠标点击事件检查：

- 点击打开纸片：焦点在第一项，但不画圈；按一次 Tab 后圈出现在纸片里。
- 点击「算了」：焦点回到格子，不画圈。
- 回车打开纸片、回车按「算了」：照常画圈。
- 触屏入口 `press_at` 点格子、点「算了」：不画圈。

改后全过；在 main 上失败 32 项（点按后都画了圈）。背篓格子、拖拽、摆放、按钮状态、「算了」焦点、HUD / 菜单键盘焦点和触屏模态套件全部通过。

## 已知限制

- 刚打开背篓时，「合上背篓」本身会亮一圈（截图都在点过格子之后拍，焦点已离开它，所以图里看不到）。那一处焦点在 Main 的 `_show_basket` 里交出，这个方法正被 #720 修改，等 #720 合入或关闭后再按同样方式处理，本片不碰。
