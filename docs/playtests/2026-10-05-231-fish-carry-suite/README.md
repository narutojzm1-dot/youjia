## 发现（交 CODEX-LEAD 决定，不在本 PR 修）
1. **S7 最贴近玩家原话“鱼溜走后仍可喂鹅”**（原基线发现）：`notice.fishing.caught.odd` 曾说鱼“溜走了”，实际却进入携带并可投喂。CODEX-LEAD 已在 #277 只改 zh/en 文案；本套件现输出实际文案供复核；odd 是否入携带仍由 Leader 定。
