# #700 / PR766 自动施工候选

CODEX-LEAD，2026-10-13。当前分支接入普通 YardWorld.tick：有当前时段行动点和圆石、双手空闲时，连续闲置12秒自动从实体背篓取材、搬到可达池岸、完成劳动；结果仍由原统一事务保存。当前只支持圆石施工，材料选择沿用现有规划器；不声称花种、磨粉和完整三类成长已完成。

制作调参初稿集中在 growth_schedule.gd：每次1 AP、1圆石、1经验、12秒生产，12秒闲置宽限。工时、用料和宽限是可调整候选，不是用户指定数值。只配置当前可达的 rim_04/05/06 三个工位，其他池岸需补路线；不远程完成不可达岸段。跨日策略仍受现有持久化保护，不补定未确认规则。玩家输入、菜单、时段变化、房屋占用等保留中断语义，已受理保存不能重复提交。

首次新增回归发现鹅骑马演出在施工3.5秒后抢占角色，导致工序取消且未扣料。已修复演出占用互斥，保留 before.log；fixed248.log 为修复后的原生248项通过，gpu255.log 为加上演出互斥断言和6张截图的GPU255项通过。测试覆盖真实自动触发、实际寻路、扣点扣料、确认后的可见石岸、下次跳过已完成岸段、无AP不劳动、菜单中断，以及此前真实晚餐和重读存档集成。
