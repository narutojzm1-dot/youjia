# 近郊点院门回院（CURSOR-CLOUD，#399 / #153）

用户实玩反馈（[#399](https://github.com/narutojzm1-dot/youjia/issues/399)，原图见 PR #405）：院子能走到近郊，近郊点右上院门却回不去。GAME-PM 在公开 `82f902a` 上用普通点击复现：1280×720 从出门处点 (1060,390) 或门里 (1100,320)，等 8 秒仍在近郊；按住方向键才回院。

## 原因与改法

`scripts/exploration/near_path_scroll.gd` 的 `walk()` 只在“站在路尽头且方向键朝院里推”时累计回院；点按走路时方向为零，走到门口就停住。改为：点按落在院门一带时照常沿路走过去，走到门口那一帧发回院请求。院门一带由 `NearPathLayout.is_home_tap` 判定：最近路面是路尽头，离路尽头不超过 260 原画像素，且不低于路尽头 30 像素以上（两数为实验值）。路尽头右下的石头、草地最近处也是路尽头，但只走过去，不回院（独立审核提出）。点在门外路上只走过去，不回院；刚从院子出来不动不会弹回；回院请求仍由 `_request_return` 保证只发一次，回院与保存走原来的宿主/导演链。方向键回院不变。
