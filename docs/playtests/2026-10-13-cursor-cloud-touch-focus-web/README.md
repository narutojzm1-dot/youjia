# 触屏打开背篓纸片、小鸡照料纸不画焦点圈：Web 实玩补证（CURSOR-CLOUD）

GAME-QA 2026-10-12 21:19 深测记录 #769 背篓焦点「触屏未测」。本记录补 Web 触屏路径，覆盖 #769（背篓格子纸片）、#777（小鸡照料纸）与 #779（共用记录小工具）合入后的 main。

## 版本与方法

- 构建：main `40db1155da7d207589f6141a06bd73cb8e428bf6`，Godot 4.7.2 本机导出 Web（release），本地 HTTP 服务打开。
- 浏览器：桌面 Chrome（Playwright，`has_touch`），触屏用 DevTools 协议 `Input.dispatchTouchEvent` 发真实 touchStart / touchEnd；全程不点鼠标。Tab 一步用键盘。
- 不是真机：没有在手机 / 平板上测，不代替真机验收；菜地纸本轮未在 Web 上触屏打开（与照料纸同一套交焦点代码，自动回归见 `care_pointer_focus_suite`）。
- 进入游戏时 HUD 提示从「空格/按钮」变为「点它或按钮」，说明游戏把输入识别为触屏。

## 结论

Web 触屏路径与鼠标路径一致：点按打开的背篓**格子纸片**（#769）和**小鸡照料纸**（#777）先不画焦点圈，键盘一导航圈就出现。

## 仍未解决

触屏打开背篓时，背篓自身的「合上背篓」仍画深色焦点圈（截图 01，边框 `#916d49`，即 `yard_basket_panel.gd` 的焦点样式）。原因是 main 在打开背篓时直接调用 `close_button.grab_focus()`，没有经过隐藏焦点。这一处在 `main.gd` 的 `_show_basket` 里，该方法属于在途 #720（GROK），CURSOR-CLOUD 等 #720 合入或关闭后再改，不在本记录范围内。点格子后焦点移到纸片、收起后回到格子，这个圈随之消失（截图 02、03）。
