# 近郊「停下看看 / 带上 / 换成 / 放回」按钮：一行放不下就折两行（CURSOR-CLOUD UI 维护）

## 玩家影响先说清

当前版本 `Main` 启动时固定 `I18n.set_locale("zh-CN")`，玩家选不到英文，所以英文超宽现在玩家看不到。本次是给英文界面做适配储备，问题和修复都由原生套件证明。Web 实玩只确认中文表现与 main 一致。

## 修前（main，原生套件测得）

按钮宽度固定，但 Godot 按钮的最小宽度跟着文字走：文字比按钮宽时，按钮被撑宽，越出屏幕左边。

| 英文视口 | 例子 |
|---|---|
| 390×844 | 「Swap for the round stone」「Put the round stone back」，按钮左边到 x = −11 |
| 360×640 | 同上 |
| 320×568 | 底排按钮，加上「Stop and look within earshot of the brook」 |
| 280×653 | 同上 |

共 26 处失败。中文所有尺寸都放得下，没有失败。

## 修法

`scripts/exploration/near_path_scroll.gd` 新增 `_fit_button`：

- 文字一行放得下：不折行，仍是 46 高，与 main 相同。
- 放不下：按词折行，按实际行数长高。
- 底排两枚按钮取同一高度。
- 篮子、底排按钮位置和行走时的说明，都按实际高度让开。

## Web 实玩（中文，修后）

`zh-look-1280x720.png`、`zh-look-390x844.png`、`zh-look-280x653.png`：观察「坡路草边」时，「把松果放回去 / 接着走」仍是一行、46 高。

先在 1280×720 进入近郊，捡起松果、点「停下看看」，再把视口改成 280 和 390，靠缩放时的重排来验证。

另见：说明末尾的「。」会单独掉到下一行。这是另一个排版问题，本 PR 不改，作为 Cloud 下一个切片。

## 回归

`test/exploration_hud_readable_suite.gd` 新增按钮检查，覆盖中英文和 10 个视口：

- 走到四处时的「停下看看」，以及村口两句。
- 底排「带上 / 换成 / 放回」，各配三种东西名；还有「带回小院水塘」「带 beibei 回家」「再试一次」。
- 所有观察状态。

检查内容：

- 按钮在屏幕内。
- 放不下时是折行而不是撑宽，折行后高度够。
- 至少 46 高。
- 不压篮子。
- 底排两枚不重叠、同高。

在 main 的布局上跑有 26 处失败；修后 9000 多条 checks 全部通过。
