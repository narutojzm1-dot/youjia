# REQ-014 — 大鹅骑马场内摄影演出

## 当前状态

实现候选，尚无运行时游玩证据。待 PR 自动检查和 Godot Web 候选构建后，按下列步骤补充构建号、录屏/截图与实际结果；在此之前不视为已验收或发布。

## 候选触发与演出

- 假期当天前 45 秒不触发；之后玩家在鹅马附近停留观察 3.5 秒，鹅马间距不超过 190 世界像素且玩家离事件中心不超过 225 世界像素时触发。
- 远景 1.25 秒 → 旅人视线感镜头 1.4 秒 → 鹅骑到马背、完整水彩姿态交替扑翼 3.2 秒 → 现场拍立得收入手账。
- 玩家移动、点选移动目标或牵行时应立即打断演出，不拍照、不消耗记录机会；成功照片在当前存档中只自动拍摄一次。
- 预期手账题词稳定保存，中英文切换后不重抽；低动效时缩短镜头黑边并保持场景姿态清楚。

## 待执行的复核

1. 新存档中走到鹅马附近，停留后确认镜头按远景、旅人视线、近景的顺序平滑变化。
2. 确认第一视角阶段隐藏玩家角色，鹅完整画作在马背位置交替展示扑翼；之后玩家可见并能继续散步。
3. 在远景和近景阶段分别移动/点地，确认镜头立即恢复、角色正常行走且没有照片被误存。
4. 让演出完成，打开相册确认鹅和马都在同一张真实成片内；刷新/重开存档确认照片、题词、日期保持。
5. 重开后再次靠近并停留，确认不会自动重复；手动查看历史相片不产生新记录。
6. 分别复核宽屏、窄屏与低动效设置；检查拍立得显影不遮挡操作、黑边不挡 HUD。
