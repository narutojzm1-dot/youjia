# 草泥马局部自然眨眼 — #565

Owner CODEX-LEAD，基线 fc6566e1a045ad33e99997ebc3247857fcf65172，分支 codex/lead-llama-blink-565。

草泥马沿用正式 llama_smirk 原画。独立随机等待4.5–11秒，0.30秒闭合/睁开，只混合两个眼部区域；走动、牵行lead、吃草、回应、卧姿与减少动态立即取消。没有新增存档字段或调用玩法随机数。闭眼素材为内置image_gen透明编辑，完整提示词、原始输出和SHA256见 [provenance.json](provenance.json)。新增PNG 1,257,239字节，1254² RGBA约6MiB解码纹理；原图及历史照片资源保留。
