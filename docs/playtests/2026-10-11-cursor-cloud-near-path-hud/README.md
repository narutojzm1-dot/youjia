# 近郊小路地名与操作提示：夜里读得清，窄屏不出屏、不压按钮（CURSOR-CLOUD UI 维护）

普通 Web 导出，浏览器模拟视口（非手机实机）。修前截图来自 main 同一布局代码。近郊内容归 ASSISTANT；本次只改界面的 `NearPathScroll._build_hud` / `_layout` / `_fit_hint` 与 `Main._sync_regional_clock` 的近郊分支，与 #612 改的 `_start_reveal` / `_draw_items` 是不同方法。

## 修前

- `before-844x390.png`、`before-640x300.png`：「院外近郊」是浅色字直接压在景上，黄昏和夜里几乎看不见。底部操作提示是浅灰色字直接压在景上，对比度不足。
- `before-280x653.png`：地名被「歇一会儿」按钮盖住。操作提示只有一行，越出屏幕，截在「R 回」。

## 修法

- 地名和操作提示都垫上半透明纸片（与左上时钟药丸同一种：纸色 0.90、描边、圆角 8）。提示字从浅灰改为墨色。
- 地名宽度贴合文字。左侧放得下就和暂停按钮同一高度；放不下（窄竖屏）就移到按钮下面，下方内容随之下移。
- 时钟贴在地名下方，宽度跟随地名（96–180）。
- 地名和暂停按钮之间留 10px（与两枚按钮之间同宽），英文地名在 480 宽矮横屏也能留在按钮左边。
- 观察说明与地名、时钟同一高度时，挪到地名与时钟右边，宽度尽量不收（不窄于 240），免得折成多行压到左下篮子；放不下才移到时钟下面。
- 操作提示按文字宽度居中，最多 3 行自动换行。背篓按提示的实际高度上移。

## 修后

`after-1280x720.png`、`after-844x390.png`、`after-640x300.png`、`after-390x844.png`、`after-280x653.png`：地名和时钟在夜里也读得清。280 宽时地名移到按钮下方，提示换成两行，完整显示在屏幕内，不压背篓。

## 回归

新增 `test/exploration_hud_readable_suite.gd`：用真实 Main 进入近郊，覆盖中文和英文、10 个视口（1280×720、844×390、640×300、568×320、390×844、360×640、320×568、280×653、700×300、480×320），分别检查行走中、靠近「小溪」、观察全部五处看景点（gate、brook、shade、slope、leaf_pile）：

- 纸片不透明度，字与纸的对比度 ≥ 4.5:1，样式与时钟一致。
- 地名和时钟在屏幕内、放得下文字，并且互不重叠，也不压暂停、回院、细看按钮和观察说明。
- 观察说明在屏幕内，不压篮子及其名字，也不压暂停、回院、拿起、继续走按钮。
- 操作提示在屏幕内、不超过 3 行、高度够、不截字，也不压背篓。

修前 280 宽有 26 处错误。独立审核第一轮指出：英文矮横屏（640×300、700×300、480×320）的观察说明被挤到时钟下面，会压到篮子。为此加了说明对篮子和按钮的检查；按第一轮的布局跑，有 9 处失败。修后 2235 checks 通过，已登记进 `tools/verify_daily_life.sh` 与 `tools/lib/godot_suite_completions.tsv`。
