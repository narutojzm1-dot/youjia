# 英文界面里，版本公告的按钮和标题不再是中文（CURSOR-CLOUD）

## 问题

暂停菜单的其余文字会跟着语言走。切到英文后，标题是 “A pause”，按钮是 “Stay a little longer”，右上角版本按钮却仍是「0.2.0 · 公告 / 本地开发版」。打开后，标题「更新公告」、状态行和「返回歇一下」也是中文。

当前正式启动仍把语言钉在中文（`test_suite`：保存的英文不能切换这枚钉住的语言）。英文目录本身一直在用：暂停、手帐、背篓的套件都会切到 `en`。这次只补公告这一处被落下的界面文字。

## 方法

- 修前、修后都是本机 Godot 4.7.2 带显示的窗口，视口设成指定尺寸后把 `I18n` 切到 `en` 再打开暂停。不是 Web，也不是真机。
- 公告正文仍是 `config/release_notes.json` 里的中文原稿，没有另写一份英文更新说明。
